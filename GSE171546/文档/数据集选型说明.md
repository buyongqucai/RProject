# GSE171546 数据集选型说明

## 基本信息

| 项目 | 内容 |
|------|------|
| 编号 | [GSE171546](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE171546) / [PRJNA720038](https://www.ncbi.nlm.nih.gov/bioproject/720038) |
| 物种 | 小鼠 |
| 组织 | 心肌 |
| 模型 | CLP（盲肠结扎穿孔） |
| 设计 | 24 / 48 / 72 h 时序 |
| 类型 | bulk RNA-seq |

## 为何选择

- 直接研究 **脓毒症心肌损伤** 的时序转录变化
- 文献报道 CLP 后 24–72 h 共 5607 个 DEG
- 适合分析 PI3K 等通路在 SIC 中的作用

## 数据来源

- GEO 补充文件 / SRA（**无 Series Matrix**）
- 需下载 `GSE171546_RAW.tar` 或 SRA FASTQ

## 本项目策略

- 推荐对比：**CLP 72h vs Sham**（或各时间点 vs Sham）
- 方法：DESeq2（count 矩阵）或 limma-voom
