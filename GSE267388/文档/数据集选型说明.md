# GSE267388 数据集选型说明

## 基本信息

| 编号 | [GSE267388](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE267388) |
| 物种 | 小鼠（C57BL/6） |
| 组织 | 心肌 |
| 主题 | LPS 诱导脓毒症心肌功能障碍 bulk RNA-seq |
| 类型 | **bulk RNA-seq**（非单细胞，无法绘制 UMAP） |
| BioProject | PRJNA1111387 |

## 官方样本（GEO，共 10 个）

| 分组 | 样本 |
|------|------|
| PBS（对照） | Heart_PBS_rep1–5（n=5） |
| LPS（脓毒症） | Heart_LPS_rep1–5（n=5） |

## 数据下载

- 官方文件：`GSE267388_gene_expression.xls.gz`（FPKM/TPM 矩阵，~1.4 MB，见 `源数据/下载清单.json`）
- FTP：`https://ftp.ncbi.nlm.nih.gov/geo/series/GSE267nnn/GSE267388/suppl/`
- **重要更正**：该 xls 除 `fpkm_WT_{LPS,PBS}_1..5`（10 个真实重复）外，还含
  `average_fpkm_WT_LPS/PBS` 两个**均值汇总列**。早期正则 `fpkm_WT_(LPS|PBS)` 误将均值列
  当作样本，会伪造重复、抬高显著性。现已收紧为 `^fpkm_WT_(LPS|PBS)_[0-9]+$` 并剔除
  含 `average` 的列，确保严格 5 vs 5。

## 分析策略

- bulk 差异：limma-voom（LPS vs PBS）
- **图集品类与 scRNA 数据集对齐（18 张）**：火山图、质控箱线图/PCA、PCA、Top50 热图、
  GO/KEGG 富集、细胞比例环图、分组堆叠柱图，以及 3 张 **UMAP**（细胞类型 / 免疫聚类 / 免疫谱系）。
- bulk 的 UMAP 为**样本级 marker 签名 UMAP**（基于真实 bulk 表达与 `CARDIAC_MARKERS` /
  `IMMUNE_LINEAGE` 得分矩阵，每个点=一个生物学样本，非单细胞坐标），见 `04_可视化.R` +
  `共享脚本/工具_bulk可视化.R`。
