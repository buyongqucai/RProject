## 2. 每个编号模块的子文件夹（敲定 · 2026-10-15）

```text
0N_模块名/
  README_模块说明.md
  代码文件/                      # 仅脚本
  数据文件/                      # 与代码文件同级
    原始数据/                    # 送入外部库/工具的输入；目录名必须带来源库
    结果数据/                    # 工具输出表 + 后续导入/分析表（CSV/TSV/JSON 等）
  结果文件/
    图片文件/                    # 产物图
    报告文件/                    # 本模块阶段/方法报告
```

### 2.1 原始数据 vs 结果数据（判定原则）

| 判定 | 放哪里 | 含义 |
|------|--------|------|
| **原始数据** | `数据文件/原始数据/` | 你**上传/提交给**外部数据库或工具的输入；或从库**下载后尚未经本模块分析**的抓取包 |
| **结果数据** | `数据文件/结果数据/` | 外部库/工具的**输出文件**，以及脚本基于该输出做的拓扑/富集/汇总等分析表 |
| **图片 / 报告** | `结果文件/{图片文件,报告文件}/` | 图与文字报告；**不再**在 `结果文件/` 下挂 `数据文件/` |

**PPI / STRING 示例（强制对齐）：**

| 内容 | 归属 |
|------|------|
| 上传到 STRING 的靶点基因列表（Main / Full） | `原始数据/STRING数据库_上传靶点清单/` |
| STRING 导出边表（如 `STRING_*_score900.tsv`） | `结果数据/` |
| 由 STRING 边继续算出的 MCC、MCODE、富集、五层网等 | `结果数据/`（后续导入分析） |

禁止把 STRING **输出**误放进 `原始数据/`；禁止只把上游 C 集当「PPI 原始数据」却缺少上传清单。

### 2.2 原始数据命名（强制）

目录名格式：`{来源数据库}_{内容简述}`  

示例：

| 目录名 | 含义 |
|--------|------|
| `STRING数据库_上传靶点清单/` | 提交 STRING 的基因列表 |
| `SEA数据库_SEA原始/` | SEA 批量预测原始 JSON |
| `SwissTargetPrediction_STP原始/` | STP 导出 CSV |
| `外部数据库_多源/CTD/` | CTD 化学–基因 |
| `RCSB与PubChem_对接结构工作区/` | 对接用受体/配体结构 |
| `RCSB与对接姿态_MD输入_Top3/` | MD 初态 |

禁止只写 `数据/`、`raw/`、无来源的 `输入/`。  
若本模块消费上游：可在 `原始数据/上游模块_*` 保留副本（允许重复），但**本步工具输入**仍须按来源库命名单独落盘（如 STRING 上传清单）。
