## 1. 图片怎么读

### 1.1 韦恩图（`图片/韦恩图/`）

| 文件 | 含义 | 怎么看 |
|------|------|--------|
| 疾病数据库可视化韦恩图 | 多库疾病基因集合关系 | 看各库独有与交集；下游常用**并集或按规范过滤后的交集基因** |
| 疾病药物交集韦恩图 | 药物靶点并集 ∩ 疾病基因 | 中间交集即**药病交集靶点**，后续网络/富集的核心输入 |

### 1.2 补充柱状 / UpSet（`图片/补充_技能扩展/`）

| 文件 | 含义 | 怎么看 |
|------|------|--------|
| 单药疾病交集柱状图 | 各味药与疾病交集基因数 | 柱越高，该药贡献的交集靶点越多 |
| 成分疾病交集柱状图 / 按药柱状图 | 成分层面的药病交集 | 识别枢纽成分；按药分面时看方剂内部差异 |
| GO_BPCCMF 柱状图 | GO 三大类富集条形 | 配合气泡图看功能主题 |
| 药味成分交集 UpSet 图 | 多药成分集合交集 | **优于多集合韦恩**；左侧 Set size=各药成分总数；上方柱=特定交集大小；点阵连线=参与该交集的药；`same*` 常出现在多药交集柱 |
| 药味通路覆盖热图 | 药味×Top20 通路 | 格子数字=该药经成分链到该通路的**不同交集靶点数**；颜色越深覆盖越强；看哪几味药主攻哪些炎症/信号通路 |

### 1.3 富集分析（`图片/富集分析/`）

| 文件 | 含义 | 怎么看 |
|------|------|--------|
| BPCCMF 气泡图 | GO BP/CC/MF 气泡 | 横轴富集程度/基因比，点大小=基因数，颜色=显著性 |
| KEGG 棒棒糖图 / 柱状图 | 通路富集排序 | 优先看 Top 通路名称与 p/p.adjust |
| KEGG 圈图 | 通路–基因弦图 | 外围扇区=通路/基因，弦=归属关系 |

### 1.4 网络与 PPI（`图片/网络图/`、`图片/PPI/`）

| 文件 | 含义 | 怎么看 |
|------|------|--------|
| 药物有效成分疾病靶点通路网络图（及椭圆布局） | HCTP 四层网络 | **A 药 / B 成分 / C 靶 / D 通路**；看枢纽靶点、共享成分 `same*`、通路标注 |
| 药成分靶点通路桑基图 | 筛选后的四层流量总览 | 带宽≈关联强度；色带随**药味**；节点块分列着色（药/成分蓝/靶红/通路绿） |
| 筛选成分桑基图 | 前 16 成分 **4×4 分面** | **每个子图一个成分**：药→靶→通路，便于讲清单成分作用轴 |
| string_vector / PPI 渐变图 | STRING PPI | 看蛋白互作紧密模块与 Degree 中心性 |

### 1.5 KEGG 官方通路图（`图片/KEGG官方通路图/`）

| 内容 | 含义 | 怎么看 |
|------|------|--------|
| `01_…`–`20_….png` | 富集 **pvalue Top20** 的 KEGG 官网通路地图 | 在图中定位本研究交集基因（需对照 `数据/富集分析/KEGG.csv` 的 geneID）；官方图为通路知识地图，**不是**柱状/棒棒糖的替代 |
| `00_Top20通路图清单.csv` | 排名、ID、英文名、文件名、下载 URL | 写论文时可写「通路图来自 KEGG REST `/get/{id}/image`」 |

> 学术使用请遵守 [KEGG 条款](https://www.kegg.jp/kegg/legal.html)。

## 4. 建议写作顺序（结果部分）

1. 疾病多库与药病交集（韦恩）→ 给出交集基因规模  
2. 单药/成分贡献（柱图、UpSet）

5. HCTP 网络 + 桑基总览 + 分面桑基讲清「药→成分→靶→通路」  
6. PPI 说明蛋白互作枢纽
