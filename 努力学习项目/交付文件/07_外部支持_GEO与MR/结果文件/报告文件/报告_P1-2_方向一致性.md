# 报告：P1-2 方向一致性分析（三层符号检验）

> 日期：2026-10-08 ｜ 脚本：`代码文件/16_方向一致性分析.py`
> 产物：`数据/方向一致性/方向一致性_{配对明细,代谢物汇总}.csv` + `方向一致性_摘要.json`
> 定位：执行计划风险 4（方向性缺失）对策的**数据层尝试**；结果为**方向层大多不可判定**——按阴性/边界结果如实报告。

## 1. 方法（预登记于脚本）

对每个 Tier A 代谢物 m 的每个共有 C 基因 g，取三层符号：

```text
① 代谢物 UC 丰度方向：GMMAD2 best alteration（Increase/Decrease）
② 代谢物→基因 实验作用方向：gutMGene H 边 alteration（activation/inhibition）
③ 基因 UC 表达方向：GEO logFC（仅 direction_consistent=TRUE，主队列 GSE92415）

action = sign(①) × sign(②)；action == sign(③) → concordant，否则 discordant；
② 或 ③ 缺失 → unknown
```

## 2. 结果

| 层级 | 结果 |
|---|---|
| Tier A 代谢物 | 72 |
| 可判定方向的代谢物 | **4**（Butyrate、4-Hydroxyphenylacetic acid、Hydroquinone、Indole） |
| 判定为「方向未知（仅预测边/方向缺失）」 | **68（94%）** |
| 可判定配对总数 | 17（一致 8 / 相反 9） |
| 代谢物级 | 方向混合 3、方向相反 1（Indole）、方向一致 0 |
| 被 GEO 方向不一致挡下的配对 | 6 |
| 无方向信息（预测边）配对 | 299 |

**配对级样例（丁酸，11 个可判定）：** concordant：FOS、IL10、LYZ、MUC2、PPARG；
discordant：CXCL8、IL1B、IL6、TLR4、TNF、TJP1。
模式：丁酸（UC 中 ↑）对 IL1B/IL6/TNF/TLR4 为**抑制**作用，而这些基因在 UC 中**上调**——
按预登记符号检验属 discordant；生物学上这是「代谢物作用方向与疾病状态相反」的**补偿/保护性**读法，
与「丁酸抗炎轴」文献一致，但**两种读法在横断面数据下无法裁决**，故不作方向结论。

## 3. 结论边界

- ✅ 可写：「三层方向数据仅覆盖 4/72 个候选代谢物（17 个配对），符号检验未见全局一致模式；
  丁酸等候选的作用方向与疾病表达方向呈混合格局，方向归属需实验定向。」
- ❌ 不可写：复方「逆转/恢复/调控」任一基因或代谢物；把 discordant 解读为「代谢物无效」。
- 这是风险 4 的**定量落地**：94% 配对无方向信息 = 预测边（SEA∩STP）天然无方向——
  方向层是本课题数据结构的**固有边界**，不是分析疏漏；补方向只能靠实验或文献逐对策展（可列为后续动作）。
