> 对齐统一交付规范。更新日期：2026-10-13（**数据文件内分原始/结果**；结果文件只放图与报告）  
> **原始数据命名 SSOT（全技能）：** [`样例目录与命名_SampleLayoutNaming.md`](../生信分析技能_BioinformaticsSkills/00_基础_Foundation/统一交付规范_DeliveryStandards/文档_docs/样例目录与命名_SampleLayoutNaming.md) **§2.1**（本文件 §2.1 为课题落地示例，不另起规则）。

## 1. 顶层角色

课题规范名：**三源共有靶点整合网络药理学（毒性分层）**。网络毒理学不是父项目名。

| 路径 | 角色 |
|------|------|
| `00_全流程报告/` | 全项目论文版 + 方法版（与 01 同级） |
| `01_网络药理学/` … `08_分子动力学/` | 分模块工作树 |
| `交付文件/` | 轨 B：与上表同样编号镜像 |

## 2. 每个编号模块的子文件夹（敲定 · 2026-10-13）

```text
0N_模块名/
  README_模块说明.md
  代码文件/                      # 仅脚本
  数据文件/                      # 与代码文件同级
    原始数据/                    # 外部库抓取；目录名必须带来源库
    结果数据/                    # 本模块分析产物表（原 数据文件/结果数据）
  结果文件/
    图片文件/                    # 产物图
    报告文件/                    # 本模块阶段/方法报告
```

### 2.1 原始数据命名（强制）

目录名格式：`{来源数据库}_{内容简述}`  

示例：

| 目录名 | 含义 |
|--------|------|
| `SEA数据库_SEA原始/` | SEA 批量预测原始 JSON |
| `SwissTargetPrediction_STP原始/` | STP 导出 CSV |
| `外部数据库_多源/CTD/` | CTD 化学–基因 |
| `外部数据库_多源/GEO/` | GEO 系列 |
| `RCSB与PubChem_对接结构工作区/` | 对接用受体/配体结构 |
| `RCSB与对接姿态_MD输入_Top3/` | MD 初态（PDB ID 写在体系名或 README） |

禁止只写 `数据/`、`raw/`、无来源的 `输入/`。  
若本模块不直接抓库、只消费上游结果：在 `原始数据/README_原始数据来源.md` 写清指针（指到 `03_…/数据文件/…`），并尽量把关键小表复制一份到本夹。

### 2.2 结果数据 vs 结果文件

| 放哪里 | 放什么 |
|--------|--------|
| `数据文件/结果数据/` | CSV/TSV/JSON 等**表型产物** |
| `结果文件/图片文件/` | PNG/SVG 等图 |
| `结果文件/报告文件/` | md/HTML 报告 |

**禁止**再把分析表放进 `结果文件/数据文件/`（已废止；表型产物迁入 `数据文件/结果数据/`）。

## 3. `00_全流程报告/` 内容

```text
00_全流程报告/
  README_模块说明.md

```

## 5. 轨 B

`交付文件/` 下同样 `00`–`08`。客户包内仍可用扁平 `数据文件/`（表）+ `图片文件/` + `报告文件/`；工作树必须遵守 §2。

## 6. 脚本路径约定

- 读原始：`ROOT/数据文件/原始数据/...`
- 写表：`ROOT/数据文件/结果数据/...`
- 写图/报告：`ROOT/结果文件/{图片文件,报告文件}/...`

旧路径 `结果文件/数据文件/`（表）已废止；改脚本时一并改为 `数据文件/结果数据/`。
