> 更新日期：2026-10-09（修正：强制 `*文件` 全称）

## 1. 顶层角色

| 路径 | 角色 | 放什么 |
|------|------|--------|
| `网络毒理学_菌群代谢物双交集/` | 主工作树（网毒 UC） | 见 §2 |
| `网络药理学/` | 网药工作树（暂薄） | 自有 `代码文件/`；勿混入网毒产物 |
| `交付文件/` | 对外交付包（轨 B） | `数据文件/` `图片文件/` `报告文件/` |
| `交付文件_修正版/` | 历史快照（勿再写） | 同上三夹名 |

## 2. 主工作树（网毒 UC）— 强制

```text
网络毒理学_菌群代谢物双交集/
  数据文件/                 # RAW：外部库、预测输入、对接工作区、缓存
  代码文件/                 # 仅脚本
  结果文件/                 # 与代码、数据平级
    数据文件/               # 分析产物表
    图片文件/               # 出版图（总图/机制层/…）
    报告文件/               # 阶段报告 *.md / HTML
  研究计划/                 # 研究计划、文献调研、纳入规则
  存放规范_ProjectLayout.md
```

| 旧名（禁止） | 现名 |
|--------------|------|
| `准备文件/` | `数据文件/` |
| `数据/` | `结果文件/数据文件/` |
| `图片/` | `结果文件/图片文件/` |
| 根目录 `报告_*.md` | `结果文件/报告文件/` |
| 根目录 `研究计划_*.md` | `研究计划/` |

## 3. 交付包（轨 B）

```text
交付文件/
  数据文件/
  图片文件/
  报告文件/
  README_轨B说明.txt
```

只维护一份活动交付：`交付文件/`。新图同步到主工作树 `结果文件/图片文件/` 与本包 `图片文件/`。

## 4. 脚本路径约定

- raw → `ROOT / "数据文件" / ...`
- 结果表/图/报告 → `ROOT / "结果文件" / {"数据文件","图片文件","报告文件"} / ...`
- 轨 B → `努力学习项目/交付文件/数据文件/...`

## 5. 出图禁则

禁止 draw.io / diagrams.net。流程图与统计图用课题脚本或技能仓约定引擎（Origin / PyMOL / R+ggplot），DPI≥600，PNG+SVG。
