# 报告：MR 遗传支持（轻量降级执行）

> 日期：2026-10-07 ｜ 脚本：`代码文件/14_MR轻量遗传支持.py`
> 定位：**遗传支持/假设生成**；非完整两样本 MR、非因果验证（计划 §4 Phase 5 与 §0.2 冻结决定 4）。
> 降级依据：原定 MiBioGen→FinnGen 全量两样本 MR 需 GB 级汇总统计与授权（FinnGen 填表授权、OpenGWAS 需 JWT、全量 MiBioGen genus 文件 35 GB），本环境不可得；按 2026-10-07 修订计划 §4.1 动作 4 以公开数据执行轻量版，完整版列入后续。
> 数据（2026-10-07 访问）：GWAS Catalog v2 REST（UC = MONDO_0005101，data release 2026-10-03）；MiBioGen `MBG.allHits.p1e4.txt`（18.3 MB）。

## 1. UC GWAS 位点 × 核心靶点重叠

| 项目 | 结果 |
|---|---:|
| UC curated 关联总数 | 1,361 |
| 全基因组显著（P<5e-8） | 813 |
| 显著位点映射基因（去重） | 503 |
| 落在 D（1517）内 | 157 |
| **C ∩ UC-GWAS** | **5**（AHR、CCL2、IL10、NOS2、TLR4） |
| C 侧超几何 P（背景=D） | **0.922（不显著）** |
| I₁ ∩ UC-GWAS | 28；P=0.708（不显著） |

**如实结论：** C 中存在 5 个 UC 全基因组显著位点基因（其中 AHR、NOS2、TLR4 同时是干预代谢物 Tier A 的共有靶点），
但相对 D 背景**无富集**（D 本身 GWAS 基因密度高，157/1517）。论文写法：
「核心靶点与 UC GWAS 显著位点存在部分重叠（5/78），未观察到相对疾病背景的富集，故 GWAS 层仅作
**位点级遗传佐证**，不构成集合级遗传支持」——列入局限，不做强遗传结论。

## 2. 菌群性状的遗传工具变量（IV）基础（MiBioGen）

| 项目 | 结果 |
|---|---:|
| allHits 行数（性状×SNP，P<1e-4） | 122,110 |
| **全基因组显著 IV（P<5e-8）** | **1,394** |
| 有命中的菌群性状数 | 211 |
| 最强命中 | genus.Bifidobacterium（P≈1.3e-20，N=14,778） |

**结论：** 菌群丰度性状具备充足遗传工具变量（1,394 个全基因组显著 SNP，211 个性状），
支持「菌群→UC 因果推断在数据层面可行」的方法学前提；本轻量版**未执行** IVW/MR-Egger 等估计，
完整 MiBioGen→FinnGen 两样本 MR 列为后续动作（§4.1 动作 4）。
