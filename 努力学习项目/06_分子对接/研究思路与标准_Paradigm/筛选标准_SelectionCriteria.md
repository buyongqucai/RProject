# 筛选标准（SSOT · 2026-10-12 敲定）

> **状态：** 课题执行口径。改数字/硬软规则须用户确认后改本文件。  
> **适用范围：** 复方–菌群代谢物–疾病整合网络 + 成分/代谢物对接。

---

## 0. 总序（不可颠倒）

```text
网药 I₁=F∩D  +  代谢 I₂=M∩D  →  C=I₁∩I₂=F∩M∩D
        ↓
网毒过滤 → C*（工作靶点宇宙）
        ↓
① 成分 Degree（仅成分–C* 边）→ Top 成分
② STRING PPI（C* 诱导子图 / 或全图指标限制在 C*）→ Top 靶点
③ 代谢物终筛（主面板 ∩ TierA* ∩ 非有害）→ Top 代谢物
        ↓
成分×Top靶点 与 代谢物×Top靶点 分别对接（kcal/mol）
```

**禁止：** 未过 C* 就用全网药 Degree；禁止脚本硬编码「看起来重要」的对。

---

## 1. 靶点宇宙

| 符号 | 定义 |
|------|------|
| F | 复方成分靶点并集 |
| D | 疾病靶点（项目冻结口径） |
| M | 代谢物靶点 = H ∪ (SEA∩STP)；L 丢弃 |
| C | F ∩ M ∩ D |
| **C\*** | C 减去网毒硬剔除靶点（§2） |

对接与 Degree / PPI **只允许 gene ∈ C\***。

---

## 2. 网毒过滤（硬）

### 2.1 有害小分子暴露物（配体硬排除 + 靶点硬剔除）

预登记清单：

- TMAO  
- p-Cresol sulfate  
- Indoxyl sulfate  
- Deoxycholic acid  
- Lithocholic acid  

**靶点：**  
`ToxHard = { gene | CTD 策展互作 ∩ 上列暴露物 ∩ in_C }`  
**C\* = C \\ ToxHard**

### 2.2 特殊暴露物（不整片删 C）

- LPS（PAMP）、H₂S（气体）：**不**用其 CTD 基因集去删 C（否则炎症枢纽被掏空）。  
- 二者**不得**作为代谢物对接配体；只保留毒性线索支线。

### 2.3 有益/有害注释

beneficial/harmful **不作**主面板入口过滤；有害小分子在**对接配体**层硬排除（§2.1）。

---

## 3. Top 靶点（PPI）

1. 输入：C\*。  
2. 边：课题已导出的 STRING human 边（默认 combined score ≥ 0.900，`Main_STRING_edges` / 等价 TSV）。  
3. 在 **限制于 C\* 的节点**上取排序键：  
   - 优先：C\* 诱导子图 Degree；  
   - 若诱导子图过稀：回退为「全 C 的 STRING/MCC 表中 gene∈C\*」按 Degree、mcc_like 降序。  
4. 取 **Top T = 8**（可改，须记入本文件）。  
5. 须有可用 UniProt + PDB（分辨率偏好 ≤3.0 Å，共晶口袋优先）；无结构则顺延下一名。

---

## 4. Top 有效成分

1. 边表：网药 `network.csv`（A–B、B–C）+ `成分靶点.csv`。  
2. **仅统计 target ∈ C\* 的 B–C 边** 计算成分 Degree（并可加 A–B 边计入连通度，但排序主键为 **B–C\* Degree**）。  
3. 排除：cellulose、tannins；无 PubChem 三维者顺延。  
4. 取 **Top L = 8**。  
5. 配对（**2026-10-15 用户修订：多对多**）：取**网络图 Degree 前 3 化合物 × PPI Degree 前 4 蛋白**，**全组合**对接（3×4=12 对）；已对接组合保留复用，不重复计算。对接规模遵循分子对接规范：**1 对多 / 多对多矩阵式，禁止 1 对 1 配对**（此前"每成分 1 个靶点"条款系误写，作废）。

---

## 5. 代谢物筛选（四层）

### 5.1 宇宙 / 主面板

同课题预登记 `代谢物纳入规则.md`（GMMAD2 高关联 ∪ gutMGene 人证据+疾病 ∪ 机制锚点+疾病）。全库仅敏感性。

### 5.2 靶点边

H ∪ (SEA∩STP)；单工具 L 不进核心。

### 5.3 Tier A\*（相对 C\*）

对代谢物 m，靶点集 T_m：

- `n_C* = |T_m ∩ C*|`  
- **Tier A\*：** `n_C* ≥ 1`  
- 排除 §2.1 有害小分子与 LPS/H₂S  

### 5.4 对接终筛（Top 代谢物）

排序键（降序）：

1. 是否存在 **H 边且落在 C\***  
2. `n_C*`  
3. GMMAD2 \|Score\|（UC）  
4. `pair_priority_score`（若有）  

取 **Top M = 8**。  

配对（**2026-10-15 用户修订：多对多**）：同成分轨——**多对多全组合**（网络图 Degree 前 3 × PPI Degree 前 4，3×4=12 对，已对接保留）；代谢物如入对接批次同样按矩阵式组合，**禁止 1 对 1 配对**（此前"每个代谢物 1 个基因"条款系误写，作废）。

---

## 6. 对接执行

- 单位：**kcal/mol**（FROZEN）；阈值 **−5.0 kcal/mol**（旁注约合 −20.9 kJ/mol）。  
- 重复：种子 1/7/42；盒子与共晶定心同分子对接技能。  
- 结论：结合候选；不作疗效/拮抗/减毒。  
- **旧硬编码对接对：剔除/归档，不以旧表作主结论。**
