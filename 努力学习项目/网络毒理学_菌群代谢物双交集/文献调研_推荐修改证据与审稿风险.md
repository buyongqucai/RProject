## 0. 总结

### 0.1 审计结论

| 推荐 | 是否有可核实支撑 | 支撑强度 | 可否直接写入方法 | 一句话判断 |
|---|---|---|---|---|
| 1. UC 证据优先面板作主分析、gutMGene v2.0 人类全库 278 个作敏感性 | **部分有**：数据库、GMMAD2、UC/菌群代谢物机制论文支持“疾病相关优先”；**无**统一规范规定“主分析/敏感性”这样分 | 中等；属于合理设计决策 | **可写，但须预注册并把全库作为敏感性** | 证据支持“不要全库等权”，不支持把该分层写成公认金标准 |
| 2. beneficial/harmful、ADME 只做终筛/分层，不作入口硬过滤 | **有方向性支撑**，但“不作硬过滤”是设计判断 | 中等偏低 | **可作为分析规则写入；结论必须降为分层/敏感性** | beneficial/harmful 受剂量、组织、阶段、受体影响；ADME 是药物性工具，不等于代谢物安全性 |
| 3. H/H-M/M/L 证据分层，核心依赖实证+多工具一致 | **有证据类型和工具来源**，无公认统一等级 | 中等 | **可写为预定义评分框架，不可写成外部验证过的证据分级** | 透明分层可降低等权混淆，但不能把预测一致性当作验证 |
| 4. Track A 必须有“有害暴露物—毒性靶点—不良结局—效应方向”，否则不称完整网毒 | **AOP/CTD/毒理数据库支持该逻辑**；“必须”是合规和术语底线 | 高（就定义完整性） | **必须先补齐链条，否则降称“分层网络药理学/毒性假设”** | 共享靶点或网络交集本身不能证明“拮抗”或“减毒” |
| 5. GEO、MR 只作优先级/外部支持，不写疗效或因果验证 | **有 MIAME、GEO、STROBE-MR、TRIPOD 支持** | 高 | **可直接采纳** | GEO 是公共观察数据，MR 是遗传工具推断；都不能替代干预实验 |
| 6. 对接只写结合候选，不证明药效/毒性/拮抗 | **有 AutoDock Vina 方法来源、对接局限和 PoseBusters 证据** | 高 | **可直接采纳** | 分数、姿态、MD 稳定性均为计算候选，不能替代 SPR/ITC/功能实验 |
| 7. 8 周=计算+GEO+MR+初稿；实验另需 8–16 周以上 | **没有论文可直接证明日历工期** | 低（计划假设） | **可写入项目计划，但必须列范围、资源和假设** | “8 周/8–16 周”不能冒充文献事实，应写为容量估算和里程碑 |

### 0.2 最关键的三项风险

1. **选择偏倚/事后筛选：** 如果先看结果再决定 UC 证据优先面板，主分析会被批为 post-hoc selection bias。应先写入纳入标准、证据层级、阈值和失败时的敏感性方案。
2. **“网毒”与“拮抗”过度命名：** 只有“共同靶点/交集”不能推出复方拮抗有害代谢物；缺效应方向、毒性终点和干预证据时，必须改写术语。
3. **验证叙事越级：** GEO AUC、MR 名义关联、对接分数均不能分别写成疗效预测、因果证明或结合/拮抗验证。

## 1. 逐条证据审计表

> “核心支撑”指可直接支撑方法逻辑的一手研究、数据库原始论文或权威方法文件；“方法/案例支撑”指工具论文、同领域案例或计算先例，能说明可行性但不能证明普遍规范。

### 1. UC 证据优先代谢物面板作主分析；gutMGene v2.0 人类全库 278 个作敏感性

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | UC 证据优先面板主分析；gutMGene v2.0 人类全库 278 个为敏感性，不做全库等权主分析 |
| 核心支撑 | gutMGene 原始数据库论文区分实证的微生物/代谢物–基因关系（NAR 2022，PMID 34500458；gutMGene v2.0，PMID 39475181）；GMMAD/GMMAD2 提供疾病关联、置信度/评分和文献验证候选（BMC Genomics 2023，PMID 37620754；Front Microbiol 2026，PMID 41889639）。高影响力机制论文优先使用疾病相关、实测或受体方向明确的代谢物：色氨酸–AhR 轴（Immunity 2013，PMID 23973224；Nat Med 2016，PMID 27158904）、胆汁酸–Th17/Treg（Nature 2019，PMID 31776512）。 |
| 仅方法类/案例支撑 | Sci Rep 2025（PMID 40664846）用 gutMGene 全库 277 个、SEA∩STP；Front Microbiol 2025（PMID 40625623）用 251 个、SEA∩STP；Immunol Res 2026（PMID 42696087）先用 MR/转录组收敛再接代谢物。它们能证明路线可行，不能证明“主/敏感性”分工是规范。 |
| 证据缺口 | 未找到数据库官方指南或高质量方法学共识规定“UC 面板必须主分析、全库必须敏感性”。“UC 证据优先”需用户指定：UC 人体实测、UC 机制研究、GMMAD2 评分、复方药物逆转中取哪些，是否允许跨病种外推。 |
| 审稿风险 | 高：选择偏倚、事后筛选、面板中代谢物的文献覆盖偏倚；把 GMMAD2 评分当成 UC 特异因果证据；全库 278 个是数据库版本快照而被写成固定宇宙。 |
| 可认可程度 | **中等到较高**（若预注册标准、报全库敏感性和取空/阈值敏感性）；不建议写“已有统一审稿规范要求”。 |
| 采纳方式 | **方法可写：** “主分析采用预先定义的 UC 证据面板；gutMGene v2.0 人类全库作敏感性分析。” 但先由用户确认面板清单和纳入规则。 |
| 关键词改写 | 不写“金标准代谢物面板”；写“预先定义的 UC 证据优先候选面板”。 |

### 2. beneficial/harmful 和 ADME 只用于终筛/分层，不作入口硬过滤

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | beneficial/harmful、ADME 不作入口硬过滤，放到终筛/网毒分层 |
| 核心支撑 | Nature Reviews Gastroenterology & Hepatology 2020（PMID 32076145）明确 SCFA、胆汁酸、色氨酸代谢物等存在受体、组织、剂量和疾病背景依赖；Immunity 2013、Nat Med 2016、Nature 2019 的机制研究也显示同一通路可产生不同效应。ADME/成药性工具的原始论文面向药物研发：Lipinski/Rule-of-5（PMID 11259830）、SwissADME（PMID 28256516）、ADMETlab 2.0/3.0（PMID 33893803、38572755）。 |
| 仅方法类/案例支撑 | Sci Rep 2025 和 Front Microbiol 2025 将 SwissADME/ADMETlab 放在末端候选，而非入口排除；这类案例支持“注释型终筛”，不构成规范。 |
| 证据缺口 | 没有检索到“内源性菌群代谢物不得用 ADME 做硬过滤”的权威标准；ADME 工具训练于口服药物暴露，不能自动代表结肠内源性代谢物的安全性。beneficial/harmful 也没有统一的 UC 黏膜/粪便/血浆定义。 |
| 审稿风险 | 中到高：把 ADME“不合格”误写成代谢物无效/有害；把 TMAO、DCA/LCA、H₂S 等情境依赖分子机械二分；漏掉 SCFA 等极性小分子。 |
| 可认可程度 | **较高**（作为保守分析规则和局限声明）；作为“有益/有害分类已被验证”则不认可。 |
| 采纳方式 | **可直接写入分析规则：** “ADME/成药性只作终筛注释和敏感性；不以药物样性作为内源性代谢物入口排除。” 分层结论须写“候选/假设”。 |
| 关键词改写 | 用“生物效应方向/毒性证据标签（beneficial/harmful evidence tag）”，不用“有益/有害定论”。 |

### 3. 靶点证据分层 H/H-M/M/L；核心依赖实证+多工具一致预测，单工具仅补充

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | H=实证，H/M=文献/GMMAD2，M=SEA∩STP，L=单预测；主结论依赖 H+M，报告 H、H+M、H+M+L 敏感性 |
| 核心支撑 | gutMGene 原始论文以人工整理的微生物/代谢物–基因关系为证据基础（PMID 34500458、39475181）；SEA/ligand similarity 方法有原始方法论文（Nature Biotech 2007，PMID 17287757；Nature 2009，PMID 19881490）；SwissTargetPrediction 提供配体相似性目标预测和概率/相似度输出（PMID 31106366）。 |
| 仅方法类/案例支撑 | Sci Rep 2025、Front Microbiol 2025 采用 SEA∩STP 交集；网络药理学领域批评指出 hub、数据库偏倚和预测不确定性（Front Pharmacol 2026，PMID 41800093）。 |
| 证据缺口 | H/H-M/M/L 不是 PubMed/数据库官方证据分级；也未找到高质量比较研究证明“两个预测工具取交集就等同于外部验证”。gutMGene 中 correlational 与 causal 关系仍需分开。 |
| 审稿风险 | 中到高：把 H/M 标签当成证据等级；把交集的一致性当成真阳性；单工具剔除造成过度收缩且没有报告丢失率；核心靶点仍可能来自同一配体相似性偏倚。 |
| 可认可程度 | **中等**（透明预定义、敏感性并列时）；若称“已验证证据分级”则不认可。 |
| 采纳方式 | **可写为项目内评分协议：** “证据分层用于透明排序，不替代独立实验验证。” 必须同时报告每个代谢物的来源、关系类型、工具和阈值。 |
| 关键词改写 | 用“预定义证据标签/优先级”，不用“客观证据等级”或“预测已验证”。 |

### 4. Track A 必须有“有害暴露物—毒性靶点—不良结局—效应方向”链条；否则只能称分层网络药理学

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | Track A 缺少暴露物、毒性靶点、不良结局和方向时，不能称完整网络毒理学；“拮抗”须有方向证据 |
| 核心支撑 | AOP 概念框架明确从分子起始事件/关键事件到不良结局的链条（Ankley 等，PMID 20821501，DOI 10.1002/etc.34；早期发育 AOP 框架 PMID 21750347）；CTD 作为化学–基因–通路–疾病/毒性结局的官方整理库（PMID 39385618；[CTD 官方](https://ctdbase.org/)）。 |
| 仅方法类/案例支撑 | 网药+网毒案例（Front Pharmacol 2022，PMID 36457705；Liaoning 中医药大学学报 2026，DOI 10.13194/j.issn.1673-842X.2026.07.019；PLOS ONE 2025，PMID 40986607）展示药效线/毒性线并行，但“网络毒理学”命名并不统一。 |
| 证据缺口 | “网络毒理学”没有像 CONSORT/STROBE 那样的统一命名与最低报告规范；AOP 是毒理学概念框架，不是本课题已经满足链条的证明。效应方向、剂量、组织、UC 阶段和不良结局仍须用户选择。 |
| 审稿风险 | **非常高（若缺链条）：** 网毒定义不充分、共同靶点误写成毒性靶点、交集被误写成“拮抗/减毒”。 |
| 可认可程度 | **较高**（补齐链条并把结论写成候选 AOP/毒性机制假设）；缺链条时审稿人很可能要求改名或大幅降级。 |
| 采纳方式 | **这是术语门槛，不是可选敏感性：** 每个有害暴露物至少记录身份/来源、毒性靶点及证据、不良结局、效应方向、剂量/组织/阶段、证据级。否则标题/摘要/结论使用“毒性分层网络药理学”或“毒性线索网络分析”。 |
| 关键词改写 | “拮抗毒害代谢物候选轴”可保留为假设；不能写“复方拮抗毒性”“减毒机制”除非有方向和干预证据。 |

### 5. GEO 和 MR 作为优先级/外部支持，不写成疗效或因果验证

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | GEO/MR 仅作优先级、外部支持和假设生成；GEO AUC 不等于疗效预测，MR 不等于因果证明 |
| 核心支撑 | GEO 的定位是公共表达数据库（PMID 11752295；[NCBI GEO](https://www.ncbi.nlm.nih.gov/geo/)）；MIAME 要求交代实验设计、样本、平台和数据处理（PMID 11726920）。MR 的 STROBE-MR 报告规范要求清楚报告暴露/结局定义、工具变量、假设、敏感性和局限（JAMA 2021，PMID 34698778；BMJ E&E，PMID 34702754）。TRIPOD 支持预测模型须区分开发、验证和用途（PMID 25569120）。 |
| 仅方法类/案例支撑 | Immunol Res 2026（PMID 42696087）把 MR、转录组和预测靶点作为收敛层，但其 MR 菌属在 FDR 后无显著；Sci Rep 2025（PMID 40664846）和 Front Cell Infect Microbiol 2026（PMID 42698445）的 GEO/机器学习结果仍属计算候选。 |
| 证据缺口 | 不能从数据库或 STROBE-MR 自动推导“MR 不能做因果”；正确表述是“因果解释依赖工具变量、方向、样本重叠、异质性和敏感性，名义关联不能替代因果证据”。GEO 队列是否匹配 UC 亚型、治疗、年龄、组织和平台须用户确认。 |
| 审稿风险 | 高：把 GEO 差异表达或 ROC AUC 写成疗效/诊断验证；把 MR 名义关联写成因果；暴露定义含糊、方向相反、样本重叠、未做多重校正。 |
| 可认可程度 | **高**（作为外部支持）；写成疗效或因果验证会被强烈挑战。 |
| 采纳方式 | **可直接采纳并写入方法：** “GEO/MR 为外部支持、优先级和敏感性分析，不作为疗效或因果验证。” |
| 关键词改写 | “遗传支持/方向性提示/外部一致性”优于“因果验证”“疗效预测”。 |

### 6. 对接只写结合候选，不证明药效、毒性或拮抗

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | 对接只输出结合候选/姿态假设；不证明结合、药效、毒性或拮抗 |
| 核心支撑 | AutoDock Vina 原始方法论文是评分函数和搜索算法论文（PMID 19499576），其产物是计算姿态/分数；Chem Sci 2024 PoseBusters 对接姿态可能物理不合理且难以泛化（PMID 38425520）。需要真实结合可由 SPR/ITC/X-ray/功能实验补足，这不是对接分数可替代的。 |
| 仅方法类/案例支撑 | Sci Rep 2025、Front Pharmacol 2022、PLOS ONE 2025 等均把对接列为候选层；方法学批评见 Front Pharmacol 2026（PMID 41800093）。 |
| 证据缺口 | “−20.9 kJ/mol（约 −5 kcal/mol）”没有普适药效阈值；Vina 分数受口袋、质子化、金属、电荷、去溶剂化和配体大小影响。MD 稳定也不是结合/功能证明。 |
| 审稿风险 | 高：用分数排序当亲和力、把稳定构象当药效/毒性、把共同靶点对接成“拮抗证据”。 |
| 可认可程度 | **高**（作为候选筛选和可视化）；越级解释会被明确质疑。 |
| 采纳方式 | **可直接采纳：** “分子对接用于提出结合姿态/候选配对，不能替代实验结合或功能验证。” |
| 关键词改写 | “binding candidate”“predicted pose”“computationally prioritized pair”；不写“verified binding/validated mechanism”。 |

### 7. 8 周定义为计算+GEO+MR+初稿；实验另需 8–16 周以上

| 项目 | 核验结果 |
|---|---|
| 推荐原文 | 8 周覆盖计算、GEO、MR、对接、图表和初稿；动物/代谢组/机制实验另计 8–16 周以上 |
| 核心支撑 | 未找到论文报告“数据库代谢物清单需 8 周”或“实验必须 8–16 周”。DSS 结肠炎方案有可引用的实验协议（Nat Protoc 2017，PMID 28569761），但只支持实验设计时长不能直接外推项目日历工期。 |
| 仅方法类/案例支撑 | 已发表计算论文通常报告数据库规模和步骤，不报告投入工时；动物、16S、代谢组、FMT、qPCR/WB 的批次、平台等待会导致工期大范围变化。 |
| 证据缺口 | “8 周”是项目容量假设，取决于数据是否已交付、脚本是否可复用、GEO/MR 质控是否顺利、是否包含图和返工。8–16 周实验也未定义动物房排队、样本量、重复批次、分析和写稿。 |
| 审稿风险 | 低到中（方法风险）；高（承诺风险）：如果把计划工期写成研究证据，审稿人不会接受；如果论文声称完成实验但实际未做，会构成范围/真实性问题。 |
| 可认可程度 | **作为项目管理假设可认可；作为文献事实不认可。** |
| 采纳方式 | **可写入项目计划，不写进论文方法作为证据。** 明确“8 周=计算+公共数据+初稿，单人、脚本复用、数据齐备”；实验工期另列场景估算和触发条件。 |
| 关键词改写 | “计划上限/容量估算/里程碑”，不写“文献显示全量代谢物需要 8 周”。 |

## 5. 术语和报告底线

### 5.1 推荐表述

- **“候选/提示”：** 预测靶点、代谢物–靶点配对、富集通路、对接姿态、MR 遗传支持。
- **“证据优先候选面板”：** 预先定义、按来源和方向筛选的代谢物集合；不写“已验证面板”。
- **“毒性线索/毒性分层网络药理学”：** 仅在没有完整暴露物–毒性靶点–不良结局–方向链条时使用。
- **“拮抗候选轴”：** 需方向相反、剂量/组织/阶段和干预或实测支持；否则仅写“共同调控假设”。
- **“外部一致性/遗传支持”：** GEO/MR 的正确层级；不写疗效/因果验证。

### 5.2 必须避免

- “8 周已完成全量代谢物机制验证”；
- “SEA∩STP 交集证明靶点”；
- “ADME 不通过故排除代谢物”；
- “AUC 证明复方疗效/诊断已验证”；
- “MR 证明菌群代谢物导致 UC”；
- “对接证明结合/拮抗/减毒”；
- “所有 SCFA 有益、所有 DCA/LCA/H₂S 有害”。

## 7. 最终审计判断

**可以采用：** GEO/MR/对接的降级措辞、网毒链条门槛、ADME 非入口硬过滤、预定义证据标签和全库敏感性。  
**必须拍板：** 主结局、主面板、物种/基质、F/D/背景宇宙、不良结局、GEO/MR 暴露与方向、统计主次终点、动物边界和“网毒/拮抗”术语。  
**建议降级：** beneficial/harmful、H/H-M/M/L、MR、GEO AUC、对接和全库 278 个，不作因果、疗效、安全性或机制验证。  
**工期判断：** “8 周”只能作为计算+公共数据+初稿的项目容量估算；没有任何已核实论文把它作为研究事实或实验闭环工期。
