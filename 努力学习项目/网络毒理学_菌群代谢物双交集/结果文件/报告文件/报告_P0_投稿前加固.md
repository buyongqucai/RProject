## 1. P0-1 高危 D 子集敏感性（执行计划风险 6 对策）

**预登记（先于交集计算）：** HC-D = D(1517) 中被 ≥2 个来源库（GeneCards/TTD/DrugBank/OMIM/CTD）支持的基因。
库数分布：1 库 1364、2 库 145、≥3 库 8 → 取 ≥2，**HC-D = 153 基因**。

| 指标 | 原口径 D=1517 | HC-D=153 |
|---|---:|---:|
| I₁ | 291 | 45 |
| I₂ | 165 | 39 |
| **C** | **78** | **19**（保留 24.4%，Jaccard 0.244） |
| 超几何 P（各自为宇宙） | 1.57e-18 | **0.0026（仍显著）** |
| 干预代谢物 Tier A | 72 | **32 稳健核心**（丢失 40） |

**解读（关键）：**
- **显著性扛住了高危子集**（p=0.0026）——交集不是靠单库基因堆出来的，这一点可以写进正文。
- 但保留率仅 ~1/4，Tier A 从 72 缩到 32：**丢失的 40 个几乎全是核苷/糖类代谢物**
  （脱氧腺苷、肌苷、麦芽糖、葡萄糖磷酸酯……），它们依赖的疾病侧靶点（CA2/CA9/SI/NT5E 等）多为单库基因。
- **存活的 32 个正是证据最厚的一层**：丁酸、苯丙氨酸、吲哚-3-乙酸、4-羟基苯乙酸、色氨酸、
  谷氨酸、胆酸/鹅胆酸等（含全部6个实证 H 代谢物）。
- 已在最终交付表新增两列：`n_C_HC_D_core`、`in_HC_D_robust_core`（主面板 32 / 全库 102）。

**论文写法：** 主表仍报 72（预登记口径），但正文与摘要的「稳健候选」引用 **HC-D 核心 32 个**；
40 个外层候选降级为「依赖单库疾病基因的探索性候选」。这反而把证据分层做实了。

## 2. P0-2 UC vs 克罗恩特异性对照（Open Targets 对称取数）

UC=MONDO_0005101，CD=MONDO_0005011（OLS4 核验），关联分数 ≥0.1 主阈值（≥0.3 严格对照）：

| 指标（score≥0.1） | UC | CD |
|---|---:|---:|
| OT 强关联靶点数 | 850 | 504 |
| D(1517) 落入 | 286（18.9%） | 190（12.5%） |
| **C(78) 落入** | **28（35.9%）** | 15（19.2%） |
| C 的超几何（OT 并集为宇宙） | **2.7e-12** | 2.8e-06 |
| C 的 UC-only vs CD-only Fisher | OR=3.07，**p=0.174** | — |

score≥0.3 时：C 在 UC 9 个 vs CD 10 个，无偏好（p=1.0）。

**解读：** C 在两个病上都显著富集（IBD 共享炎症核心，符合预期）；中等阈值下 C 对 UC 有**偏好趋势**
（36% vs 19%，OR≈3.1）但未达显著；严格阈值下无差异。D 本身也偏 UC（18.9% vs 12.5%），C 的 UC 偏好
只是放大了这一基线。
**论文写法：** ✅「C 富集于 UC 强关联靶点，并与克罗恩病共享部分炎症核心（UC 偏好趋势，未达显著）」；
❌ 禁止「UC 特异性靶点集」。列入局限：疾病特异性有限，符合 IBD 研究普遍格局。

## 4. P0-4 叙事校准（针对「度分层置换 p=1.0」的结构性回应）

原叙事若以「超几何 1.6e-18 显著交集」开场，会被置换检验一枪打穿。校准为**三角印证**框架——
每一层证据都不依赖「集合富集」这一已被度结构解释的统计量：

1. **结构层（弱化 p 值，强调稳健）**：C=78 为预登记口径；**HC-D 下 19/78 仍显著（p=0.0026）**；
   度分层置换 p=1.0 如实并列，表述为「交集规模与网络度结构一致，其生物学支撑来自以下独立证据」。
2. **表达层（最硬，独立于度结构）**：GEO 双队列 63 基因方向一致、43 基因双 FDR<0.05。
3. **结构层**：9 对对接 7 对过阈值，3 种子 SD≤0.63（结合候选）。
4. **预测交付层**：72 个干预候选，其中 **HC-D 稳健核心 32 个**（6 个含实验实证）+ 结肠过滤稳健 + 全库敏感性一致。

**建议结果节顺序：** 设计与预登记 → C 构建与敏感性（含置换、HC-D、结肠、阈值）→ GEO 一致性 →
对接 → 干预代谢物预测表（72/32 分层）→ 特异性与毒性分层 → 局限（置换归零、MR 降级、特异性有限）。
