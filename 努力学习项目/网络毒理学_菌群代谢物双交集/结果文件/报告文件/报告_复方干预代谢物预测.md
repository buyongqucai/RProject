# 报告：复方候选干预代谢物预测（最终交付焦点）

> 日期：2026-10-07
> 定位：**候选/提示**级预测，不构成疗效、拮抗、减毒或因果结论（项目规范 §2）。
> 脚本：`代码文件/10_复方干预代谢物预测.py`；产物：`数据/预测/复方候选干预代谢物_{主面板,全库敏感性}.csv`、`干预代谢物预测_摘要.json`
> 口径：D=1517 冻结不变；C = I₁ ∩ I₂（三源共有靶点，主面板 78 / 全库 126）。

## 1. 预测逻辑（预登记）

对每个代谢物 m（靶点集 T_m）：

```text
n_C  = |T_m ∩ C|    与复方在 UC 疾病轴上的三源共有靶点数 → 核心干预信号
n_I2 = |T_m ∩ I2|   疾病轴汇入数（含不与复方共有的部分）

A 三源核心干预候选：n_C ≥ 1        ← 「复方可能干预」的主体
B 疾病轴·非复方共有：n_C = 0 且 n_I2 ≥ 1
C 未汇入疾病轴：其余
```

排序键：分层 → n_C ↓ → 是否含实证 H 边 → GMMAD2 UC 显著(FDR<0.05) → |score| ↓ → 核心配对优先级 ↓。
注释列：证据级 H/M、GMMAD2 UC 变化方向、有益/有害下游分层、人源菌源（gutMGene）、共享 C 基因的复方草药归属、分子信息。

**证据分层（必须在论文中并列报告）：**
- **A-H 层（实证+三源共有，n=6）**：Butyrate、4-Hydroxyphenylacetic acid、D-Mannose、Hydroquinone、Indole、Nicotinic acid —— 核心结论只依赖这一层 + 下述 GMMAD2 显著层。

- 全部 72 个 Tier A 的 GMMAD2 UC 关联均 FDR<0.05（主面板预登记纳入条件所致），方向均为 Increase——即「UC 中升高、与复方共同汇入的候选干预轴」，**方向只作提示，不推断复方使其下降**。

**毒性分层衔接：** 主面板 Tier A 中无 7 个有害暴露物（TMAO/DCA/LCA/IS/pCS 等均未进入主面板核心层）；
全库敏感性 A 类含 3 个有害暴露物，按 Phase 4 口径仅作毒性线索支线，不进主结论。

## 4. 与复方草药的落点

`formula_herbs_sharing_C` 列给出每个候选代谢物的共有 C 基因分别归属哪几味复方单药
（基于交付 `全量单药疾病交集.csv`），可直接支撑「哪味药 × 哪个代谢物 × 哪些靶点」的三元组表述，
并为对接（动作 2）的配对选择提供优先级：Butyrate–PPARG/TLR4、Indole–AHR 等。

## 5. 结论边界

支持的表述：
> 「复方与肠道菌群代谢物在 UC 疾病轴上共享三源核心靶点；丁酸等 72 个（主面板）候选代谢物与复方汇入同一靶点集合，构成**预测的复方干预代谢物候选轴**，其中 6 个有实验级实证支撑。」

不支持的表述：复方「调控/降低/恢复」某代谢物水平、疗效结论、代谢物-靶点结合已被验证（→对接仅结合候选）、因果关系。
