# 存放规范 / Project Layout

对齐：`统一交付规范_DeliveryStandards` → `样例目录与命名_SampleLayoutNaming.md` **课题交付目录**（2026-09-29）。

## 强制树

```text
网络毒理学_菌群代谢物双交集/
  数据文件/                 # RAW only：外部库、预测输入、对接工作区、缓存
  代码文件/                 # 仅脚本（*.py / *.R）
  结果文件/                 # 与代码文件、数据文件平级
    数据文件/               # 分析产物表
    图片文件/               # 出版图
    报告文件/               # 阶段报告 *.md / HTML
  研究计划/                 # 研究计划、文献调研、纳入规则
```

轨 B 客户包 `努力学习项目/交付文件/`：

```text
交付文件/
  数据文件/
  图片文件/
  报告文件/
```

## 禁止

| 旧名（已废弃） | 应用 |
|----------------|------|
| `图片/` `数据/` `报告/` | 必须用 `*文件` 全称 |
| 根目录散落 `报告_*.md` | 一律进 `结果文件/报告文件/` |
| 根目录 `研究计划_*.md` | 进 `研究计划/` |
| `准备文件/` | 已并入 `数据文件/`（raw） |

## 钩稽

- 脚本读 raw → `ROOT/数据文件/...`
- 脚本写表/图/报告 → `ROOT/结果文件/{数据文件,图片文件,报告文件}/...`
- 复用网药交付 → `努力学习项目/交付文件/数据文件/...`
