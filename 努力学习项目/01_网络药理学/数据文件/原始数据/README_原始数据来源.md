# 01 网络药理学 · 原始数据

本模块只放**药物**与**疾病**两套输入（研究计划：F 与 D）。
菌群代谢物（gutMGene / GMMAD2 / SEA / STP）、毒性（CTD 毒性分层）、结肠表达（GTEx）不放在本模块。

| 目录 | 内容 | 来源 |
|------|------|------|
| `药物数据_复方成分与靶点/` | 12 味药成分、成分靶点、F、药物–疾病交集 | 交付轨 B；成分库 TCMSP 等，见表内来源列 |
| `疾病数据_UC靶点多库/` | UC 疾病靶点合并，\|D\|=1517 | GeneCards / OMIM / DisGeNET / CTD 等，见 `疾病靶点按库` |

来源压缩包：`交付文件(1).zip`（2026-10 聊天文件）。
PPI / 富集 / 网络图是本模块**结果**，在 `数据文件/结果数据/`。
