# GSE79962 数据集选型说明

## 基本信息

| 项目 | 内容 |
|------|------|
| 编号 | [GSE79962](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE79962) |
| 物种 | 人类（Homo sapiens） |
| 组织 | 心肌（左心室游离壁） |
| 平台 | Affymetrix Human Gene 1.0 ST Array（GPL6244） |
| 样本量 | SCM 20 例；非心衰对照 11 例 |
| 数据类型 | 表达谱芯片 |

## 实验设计

- **SCM 组**：死于脓毒症且符合脓毒症心肌病诊断的心肌样本
- **Control 组**：非心衰供体心脏（nonfailing heart）
- 数据集中另有 IHD、DCM 组，**本项目已排除**，仅保留 SCM 与 Control

## 为何选择此数据集

1. **组织匹配**：直接来自人类心肌，是 SIC 研究的金标准组织类型
2. **临床相关性**：样本来自真实患者，优于纯动物模型
3. **文献广泛使用**：多篇 SIC 生信文章以该数据集为训练集或验证集
4. **上手简单**：GEO 提供 Series Matrix，可用 limma 快速完成 DEG
5. **已完成分析**：本项目已跑通完整流水线，203 个显著 DEG

## 数据来源

- 下载方式：`GEOquery::getGEO("GSE79962")`
- 本地缓存：`源数据/GSE79962_series_matrix.txt.gz`

## 局限性

- 样本为终末期组织，非动态时序
- 芯片平台需探针注释映射到 Gene Symbol
- 对照为器官捐献者而非严格健康活体

## 本项目分析策略

- 对比：**SCM vs Control**
- 方法：limma（芯片）
- 阈值：padj < 0.05，|log2FC| > 1
