# GSE190856 数据集选型说明

## 基本信息

| 编号 | GSE190856 |
| 物种 | 小鼠 |
| 组织 | 心肌（单细胞） |
| 主题 | TREM2hi 驻留巨噬细胞保护脓毒症心脏 |
| 类型 | **scRNA-seq** |

## 适用性

- **条件适合**：需 pseudobulk 或按细胞类型做 DEG，非 bulk 整体心肌 DEG
- 对比：CLP 后 3/7/21 天 vs 稳态；Trem2-/- vs WT

## 分析策略

- 仅取 WT 样本（H001–H004、H007、H009、H011），对比 CLP vs Steady。
- Seurat QC → 聚类 → UMAP → canonical marker 注释 → 免疫亚群重聚类。
- 差异分析：每组仅 2 个生物学重复，样本级 pseudobulk（edgeR-TMM + limma-voom）
  在 FDR<0.05 下**无显著基因**（min padj≈0.27，power 不足）；
  故改用单细胞标准 Wilcoxon 检验（Seurat `FindMarkers`，每组抽样封顶
  `max.cells.per.ident=3000`），得显著 DEG 1234 个（上调 235 / 下调 999）。
- 图集：UMAP（细胞类型/免疫聚类/免疫谱系）、细胞比例环图/堆叠柱图、火山图、
  质控箱线图/PCA、Top50 热图、GO/KEGG（dotplot+barplot）。
