# 数据集筛选评估

本文档评估用户提供的 11 个数据集（GSE207363 重复计一次）是否适合**脓毒症心肌病（SIC/SCM）**的人或小鼠**差异表达分析**。

## 筛选标准

1. 物种：人（Homo sapiens）或小鼠（Mus musculus）
2. 组织：心肌（heart / myocardium），非全血/PBMC/单核细胞
3. 数据类型：表达谱（芯片/RNA-seq），非 Cut&Tag 等表观组
4. 分组：存在 SCM/SIC vs 对照或可归类的脓毒症心肌损伤表型
