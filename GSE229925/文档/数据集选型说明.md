# GSE229925 数据集选型说明

## 基本信息

| 项目 | 内容 |
|------|------|
| 编号 | [GSE229925](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE229925) |
| 物种 | 小鼠（Mus musculus） |
| 组织 | 心肌 |
| 平台 | Illumina NovaSeq（bulk RNA-seq） |
| 样本量 | Sham n=4；HEF n=4；LEF n=3；NEF n=4 |
| 数据类型 | 高通量测序表达谱 |

## 实验设计

脓毒症造模后 1 天，按**左心室射血分数（LVEF）**分型：

- **Sham（S）**：假手术对照
- **HEF（C1）**：LVEF ≥ 90%（高射血分数）
- **LEF（C2）**：LVEF < 65%（低射血分数，心肌功能障碍）
- **NEF（C3）**：65% ≤ LVEF < 90%

## 为何选择此数据集

1. 直接按**心肌功能障碍表型**（LVEF）分组，贴近临床脓毒症心肌病
2. 组织为**小鼠心肌**，适合机制研究
3. 与 GSE79962（人类）可做人鼠交叉验证
4. GEO 提供 Series Matrix，可快速用 limma-voom 分析

## 数据来源

- GEO：`GEOquery::getGEO("GSE229925")`
- BioProject：[PRJNA956654](https://www.ncbi.nlm.nih.gov/bioproject/956654)

## 局限性

- LEF 组仅 3 例，统计功效有限
- Series Matrix 为标准化值，非原始 count

## 本项目分析策略

- 对比：**LEF vs Sham**（低射血分数 vs 假手术）
- 方法：limma-voom
- 阈值：padj < 0.05，|log2FC| > 1
