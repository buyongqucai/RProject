# GSE229925 差异分析结果解读

## 分析概况

| 项目 | 结果 |
|------|------|
| 对比组 | LEF（3 例）vs Sham（4 例） |
| 数据来源 | GEO 补充文件 read count 矩阵 |
| 检验基因数 | 25,459 |
| 显著 DEG | **224**（padj < 0.05，\|log2FC\| > 1） |
| 上调 | 161 |
| 下调 | 63 |

## 质控结论

- 从 `GSE229925_genes.readcount.txt.gz` 读取 57,555 个 Ensembl 基因
- 低表达过滤后保留 25,459 基因
- LEF 组仅 3 例，统计功效有限，结果宜与 GSE79962 交叉验证

## 方法说明

- GSE229925 的 Series Matrix **不含表达矩阵**（data_row_count = 0）
- 本项目从补充文件读取 **read count**，使用 **limma-voom** 做差异分析
- 基因 ID 为 **Ensembl**，富集分析使用 `org.Mm.eg.db` 转换

## 输出文件

- `结果/表格/GSE229925_显著差异基因.csv`
- `结果/图形/GSE229925_火山图.pdf`
- `结果/表格/GSE229925_GO生物过程.csv`

## 结论与建议

1. LEF（低射血分数）vs Sham 共鉴定 224 个 DEG，反映脓毒症后心肌功能障碍的转录变化
2. 建议与 **GSE79962** 人类数据取交集，筛选跨物种保守基因
3. 可进一步分析 HEF/NEF 亚型，比较不同 LVEF 水平的表达谱差异
