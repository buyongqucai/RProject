# 机器学习生物标志物 / ML-Biomarker

## 1. 数据来源

特征矩阵+标签

## 2. 数据规范（判断是否可用）

输入完整可溯源；分组/标注来自官方或实验记录；禁止编造结果数字。

## 3. 何时选用本技能

- 特征选择与预测模型（防泄漏）
- 山水用途层标签：预测

不适用：输入类型不匹配或仅需其它技能可覆盖的步骤。

## 4. 数据处理方法

分割→选择→训练→验证→解释

## 5. R 包与软件栈

| 步骤 | R包或CLI | 作用 | 备注 |
|------|----------|------|------|
| 分析 | `caret` | 核心 R 包 | |
| 分析 | `glmnet` | 核心 R 包 | |
| 分析 | `ggplot2` | 核心 R 包 | |
| 出图 | `ggplot2` + 出版级出图_PublicationPlot.R | DPI≥600 | 强制可视化规范 |

## 6. 数据可视化

ROC/重要性；**DPI≥600；SVG+PNG；中文；防遮挡**。

## 7. 数据结果解读

必须独立验证防泄漏

## 8. 能否结合其它生信

ROC、生存；出图强制 [统一可视化规范](../../00_基础_Foundation/统一可视化规范_VizStandards/技能说明_统一可视化规范_VizStandards.md)。
