## 改造策略默认值

- A 类：Bioconductor 实验包、GEO series matrix 本地缓存、TCGA 小队列；必须 `PROVENANCE.json` + `DATA_SOURCE.md` + `data_provenance=REAL`
- B 类：登录库 **导出 CSV** 为 REAL；无导出则 `BLOCKED_EXTERNAL` + 契约表
- C 类：样例保持 BLOCKED 契约桩 + 技能说明 **外部软件 SOP**（Wave1 已补 12 个）
- `run_sample.R`：`--file=` 安全路径 + source VizStandards → DeliveryStandards → 本技能脚本
