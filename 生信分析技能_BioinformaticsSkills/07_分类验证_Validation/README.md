# 分类验证沙盒 / Taxonomy Validation

本目录含：（1）历史 8 条分类代表性验证；（2）**每技能样例**总表（见 `验证总报告.md`）。

| 路径 | 说明 |
|------|------|
| `验证总报告.md` | 每技能样例 PASS/BLOCKED 总表 |
| `每技能样例_results.json` | 机器可读结果 |
| `run_validation.py` | 一键跑历史 8 条验证 |
| `验证记录_records/` | 历史各条 PASS/SKIP 记录 |
| `数据_data/` | toy 矩阵与探测文件 |

各技能可运行样例在对应技能目录的 `01_样例_sample/`（非本目录）。不改动 `书清项目/`、`山水项目/` 数据目录。
