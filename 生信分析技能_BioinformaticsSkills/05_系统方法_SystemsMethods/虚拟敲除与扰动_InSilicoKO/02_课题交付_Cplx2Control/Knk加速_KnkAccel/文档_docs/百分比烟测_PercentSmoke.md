## GPU 误差是否还要改算法

可用线沿用系数最大绝对差 < 1e-5。双精度相邻两个可表示数的间距大约是 1e-16 乘上数值本身；差到 1e-15 这一档，是同一公式在 CPU 与 GPU 上求和顺序不同，不需要改分解。
2026-10-02 01:13 在 cLTMR 质控矩阵的 6 个基因上，CPU 对 R `svd` 最大差 1.141e-16，GPU 对 R 最大差 6.054e-16。GPU 更大，但两边都低于 1e-5，大约是可用线的五万分之一。
不把 GPU 改回 Gram，也不为了追最后一位去改系数公式。这次没有新的 GPU 代码改动。
