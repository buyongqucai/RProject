# 1.4 与 1.4.3 分开用 CUDA

记录时间：2026-10-02。1 个 BLAS 线程。没有写 Formal 结果目录。

两条公式不混用。

| 版本 | 公式 | Python |
|---|---|---|
| 1.4 | 每个基因一次截断 SVD，双精度 `gesvd` | `knk_accel.versions.pcnet_14(..., device="gpu")` |
| 1.4.3 | 一次 Gram 特征分解，再解 secular equation | `knk_accel.versions.pcnet_143(..., device="gpu")` |

CUDA 只从 Python 调用。R 再转发一次仍然要启动同一个 PyTorch，不改变精度，所以不保留 R 调度 CUDA 的入口。R 仍负责 `sample`、`rnorm`、流形对齐和 `dRegulation`。

## 同一张 60×40 矩阵

`nComp = 3`，`q = 0.9`。1.4 参照是已安装的 Rcpp `pcNet`。1.4.3 参照是仓库 `pcNet.R`。

| 路径 | 秒 | 最大绝对差 |
|---|---:|---:|
| R 1.4 Rcpp | 1.100 | 参照 |
| Python 1.4 CPU | 0.067 | 对 Rcpp 2.642e-14 |
| Python 1.4 GPU | 0.377 | 对 Rcpp 6.117e-14 |
| R 1.4.3 | 0.110 | 对 Rcpp 7.205e-14 |
| Python 1.4.3 CPU | 0.035 | 对 1.4.3 7.716e-14 |
| Python 1.4.3 GPU | 0.154 | 对 1.4.3 8.371e-14 |

这张小矩阵上 GPU 比 CPU 慢，时间主要耗在启动。

## 800 基因 × 200 细胞

| 路径 | 秒 |
|---|---:|
| R 1.4 Rcpp | 31.02 |
| R 1.4.3 | 0.44 |
| Python 1.4.3 CPU | 0.121 |
| Python 1.4.3 GPU | 0.277 |
| Python 1.4 GPU，800 个基因都做截断 SVD | 36.047 |

1.4.3 在这张矩阵上已经快了一个数量级以上：R 里 0.44 秒对 1.4 的 31.02 秒。再放到 GPU 上没有更快。1.4 的 GPU 截断 SVD 是 36 秒，和 Rcpp 的 31 秒同一档。cLTMR 那种 425×8000 的逐基因 SVD 以前测过 GPU 约 800 秒一张网；这次没有重跑那个尺寸。

## 1.4.3 会不会漏掉计算

不会改成另一种回归。去掉某个基因，在精确算术里就是 Gram 的秩一降阶。secular equation 求的就是这次降阶之后最大的 3 个根，系数仍是 `beta = V diag(1/s) U' y`。60×40 上，1.4.3 对 1.4 Rcpp 的最大绝对差是 7.205e-14，和 GPU 对 CPU 的舍入在同一档。

没有在全部 8000 个 cLTMR 基因上做这组对照。标准差为 0 的基因、抽样随机数、张量的 3 位小数，都不在这一步里面。

## 425 细胞 × 8000 基因

合成泊松矩阵，一张网，1 个 BLAS 线程。系数还没有做 `scaleScores` 和分位数。完整记录在 `审核版_ReviewBuild.md`。

| 路径 | 秒 | 最大绝对差 |
|---|---:|---:|
| Python 1.4.3 CPU，全部系数 | 3.125 | 参照 |
| Python 1.4.3 GPU，全部系数 | 1.070 | 对 CPU 1.825e-16 |
| 分位数（改选择器之前，整表排序） | 1.795 | 与公式相同，只是排序 |
| Python 1.4 CPU，6 个基因的截断 SVD | 3.754 | 对 GPU 3.194e-15 |
| Python 1.4 GPU，同样 6 个基因 | 0.941 | 对 1.4.3 这 6 行 4.184e-16 |

这张大矩阵上，1.4.3 的 GPU 比 CPU 快。800×200 上 GPU 更慢，那次结论只对那个尺寸成立。6 个基因不能外推成 8000 次 SVD 的实测墙钟。
