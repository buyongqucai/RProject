## Tensor Core

`torch.float64` 可用，这次探针就是双精度 `gesvd`。`allow_tf32` 当前是 False，它只影响单精度矩阵乘要不要走 TF32，不把双精度送进 Tensor Core。

RTX 4080 SUPER 的 Tensor Core 做 FP16、BF16、TF32、FP8 和 INT8。这张卡没有 FP64 Tensor Core。双精度乘加走 CUDA 核心，吞吐是单精度的 1/64。PyTorch 能算双精度，但不能在这块卡上把双精度 SVD 改道到 Tensor Core。
