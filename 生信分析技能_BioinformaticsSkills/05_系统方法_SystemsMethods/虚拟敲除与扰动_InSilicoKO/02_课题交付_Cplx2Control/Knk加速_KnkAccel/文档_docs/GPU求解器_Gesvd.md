# GPU 求解器 gesvd

记录时间：2026-10-02 01:31:36。1 个 BLAS 线程。cLTMR 质控矩阵经 CPM 后是 407 细胞 × 8000 基因，只抽基因下标 [0, 10, 100, 1000, 4000, 7999]。没有做 8000 基因的整张网，也没有写 Formal 结果目录。

更改前：PyTorch 在 CUDA 上的 `svd` 默认是 cuSOLVER Jacobi（`gesvdj`）。同一批基因、同一套系数公式，对 CPU 最大绝对差 6.042e-16，6 个基因合计 1.523 秒。对 R `svd` 的上一轮记录是 6.054e-16。

更改后：显式指定 `driver="gesvd"`（QR 迭代）。系数公式仍在显卡上，没有改回 Gram，也没有把一个基因的 SVD 拆到 CPU。

- CPU 对 R `svd` 最大绝对差：1.081e-16，CPU 2.381 秒，R 19.141 秒。
- GPU `gesvd` 对 R `svd` 最大绝对差：1.902e-16，GPU 0.978 秒。本轮显存峰值 571.4 MB。
- GPU `gesvd` 对 CPU 最大绝对差：1.230e-16。
- 24 基因 × 30 细胞，GPU 对 CPU 最大绝对差：6.019e-15；CPU 0.020 秒，GPU 0.067 秒。
- 可用线仍是最大绝对差 < 1e-05。本轮 通过。

候选里还有「显卡做 QR、CPU 用 LAPACK `gesdd` 分解三角因子」。它对 CPU 的最大差是 1.298e-16，6 个基因 0.704 秒，但一个基因的 SVD 会跨两台设备，没有采用。把系数公式从显卡挪到 CPU 几乎不改变 Jacobi 的 6e-16，所以公式仍留在显卡上。
