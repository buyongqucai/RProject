# 虚拟敲除交付 SOP（Delivery Playbook）— SSOT

> **地位：** 从接诊到交付的**执行顺序与存放**唯一说明（琪乐无穷交付经验总结）。  
> **参数/信源**不在此重复：见 [`方法默认与信源登记_MethodDefaultsRegistry.md`](方法默认与信源登记_MethodDefaultsRegistry.md)；**开工顺序/引擎语义**见 [`虚拟敲除方法论_VkoMethodology.md`](虚拟敲除方法论_VkoMethodology.md)；**数据集准入**见 [`数据集筛选与M4规程_DatasetScreening.md`](数据集筛选与M4规程_DatasetScreening.md)；**图种**见 [`出图图册_VkoFigureAtlas.md`](出图图册_VkoFigureAtlas.md)。  
> **范围：** 只管虚拟敲除。差异表达、WGCNA、网药、对接等在各自技能里，不进本 SOP。

## 完成判据（一次交付做完的勾选）

- [ ] 接诊表已确认，实例计划在该课题目录
- [ ] 桌面树按 §1 建好，计数与代码在位
- [ ] 环境探测通过（§2），资源分配记录在 `_跨亚群/报告文件/资源探测_*.txt`
- [ ] 每个「亚群×基因」有该引擎自己的响应基因表 + 04 三件套 + 05 富集图或空态说明
- [ ] 方法示意（§6）与部位示意在 `_跨亚群/<引擎>/图片文件/`
- [ ] 报告入口可打开，STATUS 写明计算预测

## 1. 文件存放

桌面是金标交付，仓内是镜像与代码。同一套目录名两边一致。

### 1.1 桌面金标树

```text
<课题>/虚拟敲除/            # 例：琪乐无穷\虚拟敲除、婷婷\虚拟敲除
  存放说明.md               # 该夹只放什么、不放什么（一句话级）
  数据文件/                 # 全课题一份 raw（counts + 注释）；不进 git
  代码文件/                 # 该课题的完整版入口（只改 DATA_DIR/RESULT_DIR）
  结果文件/
    <亚群>/<引擎>/<基因>/
      数据文件/             # 响应基因、DR/KL 表、富集 CSV
      图片文件/             # 04 散点/柱、05 富集图
      报告文件/             # STATUS、计时、空态说明
    <亚群>/<引擎>/_野生型/{数据文件,图片文件,报告文件}
    _跨亚群/<引擎>/
      图片文件/             # 01 方法示意、01 部位示意、02/03 前置图
      数据文件/             # 检出率、合看表
      报告文件/             # 资源探测、运行日志、双报告 HTML、文献清单
```

| 规则 | 做法 | 完成判据 |
|------|------|----------|
| 一课题一 raw | 计数只存 `数据文件/`，留档目录读同一份 | 没有第二份 counts 复制 |
| 留档分离 | 旧选择/试跑移入同级 `留档` 夹（如五亚群留档、`_归档_*`），不与现行混列 | 现行树里只有现行选择 |
| 结果归位 | 每基因三件套（04 散点、04 柱、05 富集图或空态）在该基因目录 | 无根级散落结果 |
| 文献 | 论文 PDF 在 `_跨亚群/<引擎>/报告文件/_文献/文献_Papers/` + 清单 md | 清单写 DOI/获取方式 |
| 引擎不混 | Knk 与 GenKI 目录并列，表列名各用各的 | 无 KL 表套 `p.adj` 列名 |
| 网药/对接不进本夹 | 另夹另技能 | 虚拟敲除夹里没有对接表 |

仓内镜像：`02_课题交付_<课题>/结果文件/` 下同一套树；优化记录在 `Knk加速_KnkAccel/文档_docs`。

## 2. 环境准备

### 2.1 软件栈（保真 = 与官方一致；版本以机器实际为准并记录）

| 层 | 工具 | 备注 |
|----|------|------|
| R | R ≥ 4.4，`scTenifoldKnk`、`clusterProfiler`、`org.Mm.eg.db`/`org.Hs.eg.db`、Seurat | 富集物种跟课题（小鼠 mmu / 人 hsa） |
| Python | ≥ 3.10，GenKI（yjgeno/GenKI）、torch（CUDA 版）、`torch-geometric`、ray、scanpy | GenKI 官方环境见其 repo |
| 加速 | `完整版_143GPU_FullVersion/`（pcNet 1.4.3 GPU） | 只替换建网；后半段官方；未对齐前不称官方结果 |
| 硬件 | NVIDIA GPU（建网/训练）；CPU 并行按探测结果 | 无 CUDA 的 Knk 停下披露，不偷偷换公式 |

### 2.2 开跑前探测（强制）

1. 跑该课题 `probe_资源探测.py`（或 GenKI 的 `00_资源上限_CpuCap.py`）：CPU/内存/GPU 按比例留给系统，其余给算法。
2. 结果写 `_跨亚群/<引擎>/报告文件/资源探测_*.txt`；换机器就重新探测，不手写核数。
3. **两引擎不同机同跑**：后启动者自限线程并留出逻辑核；不提高已在跑者的 worker。一台机不同时压两个引擎。
4. CPU 名含 `285K` 的机器不训练 GenKI（实验室约定）。
5. Windows 下多进程入口必须 `if __name__ == "__main__"` 守卫；`start-process` 传参要完整可执行路径。

### 2.3 路径与仓库

代码与计划同步在仓内 `03_课题交付_<课题>/`（`代码文件/` + `文档_docs/`）；桌面只放金标交付。计数矩阵不进 git。

## 3. 数据选择（准入）

细则 SSOT：[`数据集筛选与M4规程_DatasetScreening.md`](数据集筛选与M4规程_DatasetScreening.md)。此处只留操作序：

1. 检索公共库（GEO 等），落表：登录号、物种、组织、状态、是否基因×细胞计数、作者注释能否分出目标亚群。
2. **硬门槛**（缺一不可敲）：有基因×细胞 counts（非 bulk/反卷积）、可溯源登录号、作者注释可分亚群、物种与课题一致。
3. 禁止跨 GSE/组织合并矩阵；bulk 只能做表达叙述，不拆成细胞矩阵。
4. 数据集、亚群、敲除基因的**最终选择**写进数据集筛选 SSOT 的「两台机器共用的选择」一节，两引擎共读。

## 4. 算法选择（一实例一引擎）

细则 SSOT：[`虚拟敲除方法论_VkoMethodology.md`](虚拟敲除方法论_VkoMethodology.md) §1/§3/§7。选择口诀：

| 你要的输出 | 选 | 表列语义（不可混名） |
|-----------|-----|---------------------|
| GRN 置零 + 流形距离 + FDR | `scTenifoldKnk`（默认） | `distance`、`Z`、`FC`、`p.adj` |
| VGAE 潜空间 KL + 排列稳定性 | `GenKI` | `KL`、`hit`（禁写 `p.adj`） |

- 每份实例计划 `method` 只填一个引擎；用户点名两引擎 = 两份计划、两套表。
- 1.4.3 GPU 说的是**建网公式与加速**（`pcnet_143`，`n_comp=3`，`q=0.9`），敲除后半段仍是官方张量/流形/dRegulation；报告里不写成「纯 GPU 敲除」。
- 不默认算法对照/共识；对比是用户另开的短任务（方法论 §5）。

## 5. 数据筛选（切片与过滤）

1. **亚群**按疾病/作者注释定（SSOT「两台机器共用的选择」），不按靶基因表达高低选亚群。
2. **靶基因可敲判定**：该亚群里检出细胞数 > 0 且矩阵里有该基因名；为 0 则该对不敲并记录。
3. **细胞数**只影响代表性：`nc_nCells = min(500, n−1)`；少于 500 仍可敲，STATUS 写「代表性有限」。
4. **基因过滤**：留高表达基因、必须含敲除基因、不单用 HVG、不设基因数上限（Issue #33）；`qc_minCells` 可能不写回，预处理手动按检出过滤（Issue #41）。
5. **对照基因**（各引擎各算）：建网基因里与靶基因 |Pearson| 最低、方差 > 0、非靶基因。
6. GenKI 侧：Seurat `vst` top 3000，靶基因不在名单则补入；qc 规则（`qc_minLibSize=1000` 等）见方法登记。

## 6. 各种分析（顺序与产物）

### 6.1 Phase1 前置（决定敲不敲）

| 产物 | 内容 | 位置 |
|------|------|------|
| 检出率表+柱图 | 亚群 × 靶基因检出细胞数/% | `_跨亚群/<引擎>/数据文件+图片文件` |
| UMAP / 小提琴 | 亚群定位、靶基因表达 | 同上 |
| 极化/模块分（如有） | 疾病相关模块分 UMAP | 同上 |

### 6.2 Phase2 引擎运行

| 引擎 | 顺序 | 产物 |
|------|------|------|
| Knk | QC→CPM→10 网→CP 张量→出边置零→流形对齐→DR | `_野生型/` + `<基因>/{扰动_Dr,响应基因_Responsive}.csv` |
| GenKI | GRN→VGAE 搜索 100 次→正式训练→KL→1000 次排列→hit 规则 | `_野生型/` + `<基因>/{KL排序_RankKL,响应基因_Responsive}.csv` |

响应规则各用各的：Knk = FDR < 0.05；GenKI = KL top 5% 且 hit > 95%。靶基因自身过线不算发现的靶点。

### 6.3 富集（只用该引擎自己的响应表）

GO BP/CC/MF + KEGG；物种跟课题（mmu/hsa）；BH p < 0.05 且 q < 0.2。**不预先指定通路**；05 图只画通过条目，无通过则写 `05_富集_无通过条目.txt`，不强行画 Top50。

### 6.4 出图（图种 SSOT：出图图册）

每基因三件套：04 散点（排名 vs 距离）、04 柱（Top 响应）、05 富集图或空态说明。跨亚群合看按需（重叠 Jaccard、响应对比）。图面 English、DPI≥600、SVG+PNG。

### 方法示意与部位示意（两类，缺一不可）

细则在 [`出图图册_VkoFigureAtlas.md`](出图图册_VkoFigureAtlas.md)「方法示意与部位示意」一节。要点：方法示意**数形结合**（矩阵/张量/分布/阈值线，非纯流程框），结构对齐对应论文（Knk = Osorio *Patterns* 2022 A/B/C 栏；GenKI = Yang *NAR* 2023 Fig.1 七步）；部位示意写实解剖 + 「假设示意，非定位实验结果」横幅。琪乐无穷 Knk 的金标 jpg 不重绘。

### 6.6 报告与声称

- 双报告 HTML（论文式 + 原理方法）+ `index_报告入口.html`；论文与方法论按引擎拆开。
- `STATUS.txt`：数据来源、参数、样本数、响应基因数、计算预测声明。
- 声称底线：**计算预测**；响应基因 ≠ Seurat DEG；不写湿实验敲除、不写疗效/机制已证实；对接分数不能证明敲除方向。

| 内容 | 归属 |
