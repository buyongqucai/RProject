# 多组学联合分析 / MultiOmics

## 1. 数据来源

同一或可对齐队列的多层组学结果表（差异/通路/细胞比例）；各子技能质控后产物。

## 2. 数据规范（判断是否可用）

样本可对齐或明确只做通路级叙事；物种 ID 映射固定；禁止用一层结果篡改另一层原始数据。

## 3. 何时选用本技能

- 需要跨组学整合叙事、DIABLO/相关性网络、多层证据汇总  
- 编排：多组学联合结论  

不适用：仅单层组学且无联合需求。

## 4. 数据处理方法

按证据层级：同样本多层一致 → 细胞特异与 bulk 一致 → 公共库复现 → 网络假说。工具：通路交集、mixOmics DIABLO、相关网络、Upset/Sankey。

## 5. R 包与软件栈

| 步骤 | R包或CLI | 作用 | 备注 |
|------|----------|------|------|
| 整合建模 | `mixOmics` | DIABLO/sPLS | 样本对齐时 |
| 统计 | `limma` 等 | 各层已算好则只整合 | 见子技能 |
| 网络 | `igraph`, `STRINGdb` | PPI/相关 | |
| 出图 | `ggplot2`, `ComplexUpset`/`UpSetR` + 出版级出图 | Upset/Sankey | |
| 调度 | 各 `技能说明_*.md` §5 | 分层包清单 | 禁止杜撰 |

## 6. 数据可视化

Upset/韦恩、通路对比、Sankey、整合热图；**DPI≥600；SVG+PNG**。

## 7. 数据结果解读

不一致需解释；结论写「支持/不支持假说」，避免过度因果。

## 8. 能否结合其它生信

调度：转录组、蛋白质组、代谢组、单细胞、16S、ChIP、GEO-TCGA；强制可视化规范。
