# 实现流水线（SSOT）

现行默认路径，**尚未冻结**。用户确认满意前，改流程只改本文件。

工具版本、函数名和文献见 [`信源与工具选型_SourcesAndStack.md`](信源与工具选型_SourcesAndStack.md)。本文件不重复版本号。

出图叠加 VizStandards（图面英文、DPI≥600、SVG+PNG、`出版级出图_PublicationPlot.R`、出图后 PlotQA）。文件名中英对照叠加 DeliveryStandards。

## 先选路径

完成判据：运行记录里写明路径名称。未写明之前不估计因果效应。

| 路径 | 进入条件 | 主分析 |
|------|----------|--------|
| **A. 默认** | 汇总数据、两样本、单一暴露、工具变量可做成近似独立 | 乘法随机效应 IVW（工具变量 ≤3 时固定效应 IVW） |
| **B. 多变量** | 多个暴露共用遗传预测因子，需要各自的直接效应 | MVMR；先报告条件 F |
| **C. 药物靶点 / 同一基因区** | 工具变量都落在一个基因区，或问题是药物靶点 | 该区域的 cis 工具变量 + 共定位；不以全基因组 IVW 为主分析 |
| **D. 表达或其他 xQTL** | 暴露是分子数量性状 | SMR + HEIDI |
| **E. 单样本个体数据** | 暴露和结局在同一批个体的个体水平数据 | 两阶段最小二乘；弱工具变量偏倚方向与路径 A 不同 |

路径 A 上若暴露与结局样本可能重叠，主分析数字仍先按 A 计算，再强制加上 MRlap，并按选型文档决定报告哪一个估计。

共享遗传率（LD score regression、GREML）回答的是「是否有共同遗传预测因子」。该问题不进入本流水线。

## 运行记录

每个暴露–结局对一份记录，与结果表放在同一交付目录。字段齐了，本流水线才算做完。

- 因果问题：暴露、结局、目标人群、要检验的假设（效应大小是否必须估计）
- 路径 A–E；是否怀疑样本重叠
- 数据：编号、基因组版本、祖先、样本量、效应量尺度、URL、下载日期
- 工具变量：p 阈值、clump 的 r² 与窗口、LD 人群、剔除前后个数、被 LD 面板丢掉的个数、平均 F
- 协调：`action`、因回文或等位基因不符剔除的个数
- 主分析函数名与参数；敏感性方法列表
- 异质性 Q 与 p；Egger 截距与 p
- 与 IVW 方向不一致的敏感性方法
- 图文件名；STROBE-MR 清单文件名
- R 与各包 `packageVersion()`

结果表中的估计、区间和 p 值只来自本次运行输出。样例目录 `01_样例_sample/` 的 provenance 为 **TOY**，不作为真实因果结论。

## 路径 A

### A1. 工具变量

用暴露的全基因组显著位点。TwoSampleMR 默认：`p1=5e-8`，`r2=0.001`，`kb=10000`，`pop` 与暴露祖先一致。

完成判据：记录协调前的工具变量数，以及平均 F（`MendelianRandomization::mr_ivw` 在 0.9.0 起附带 F）。平均 F≤10 时，主分析改走选型文档中的 mr.raps 或 MRlap，并在结论中写明工具变量偏弱。

赢家诅咒：工具变量的发现样本与估计暴露效应的样本分开时，在记录中写明三个样本各自的编号。发现与估计用同一样本时，同样写明。

### A2. 取结局效应并协调

结局数据只抽取这些工具变量的效应，不在结局里按全基因组显著与否再筛选。

`harmonise_data(action=2)` 用于效应等位基因频率齐全的情况。频率缺失，或大量回文 SNP 的频率接近 0.5 时，改 `action=3`（丢掉全部回文 SNP）并在记录中说明。

完成判据：记录协调后仍保留的 SNP 数。保留数为 0 时停止，不报告效应。

### A3. 主分析

- 协调后 1 个 SNP：Wald 比值。
- 2–3 个 SNP：固定效应 IVW（`MendelianRandomization::mr_ivw(model="fixed")`）。
- ≥4 个 SNP：乘法随机效应 IVW，残差标准误不低于固定效应。实现用 `MendelianRandomization::mr_ivw(model="default")` 或 `TwoSampleMR::mr_ivw_mre`。两套都跑时，两列都写入结果表。

`mr()` 默认包含的 `mr_ivw` 会做欠离散校正，结果保留在对照列，不作为主分析列。

完成判据：结果表有主分析的点估计、标准误或区间、p 值、SNP 数。

### A4. 敏感性

至少同时报告三类不同假设的结果：

1. 加权中位数（多数有效）
2. 加权众数或 contamination mixture（复数有效）
3. MR-Egger 的斜率，并单独报告截距（InSIDE；截距偏离 0 表示平均多效性偏离 0）

另外报告 Cochran Q，以及留一法。MR-PRESSO 只放在离群筛查列。

完成判据：结果表每行有方法名。结论段写明哪些方法与主分析同号，哪些不同号。不同号时，结论写成「主分析与部分敏感性结果不一致」，并列出方法名。

### A5. 方向与重叠

问题依赖「谁是暴露」时，做反向 MR（对调暴露与结局，重新选工具变量）或 Steiger 方向检验，二者都在记录中注明。

样本可能重叠时运行 MRlap。校正效应与 IVW 的差异达到该包给出的显著标准时，报告中的主数字改用校正效应，IVW 改为对照。

### A6. 图

四张图，图面英文，走 VizStandards：

| 图 | 内容 |
|----|------|
| Scatter | SNP 的暴露效应与结局效应，叠主分析与已报告的稳健方法斜率 |
| Forest | 各 SNP 的比值估计与各方法的汇总估计 |
| Funnel | 各 SNP 估计对精度 |
| Leave-one-out | 逐个去掉 SNP 后的 IVW |

完成判据：四张图均有 SVG 与 PNG，且 PlotQA 通过。图中的估计与结果表同一运行。

### A7. 报告

按 STROBE-MR 官方清单逐项填写，清单文件与报告放在一起。清单上的方法学句子指向本次运行记录，不另写一套阈值。

解读用词与指南一致：这是在所述工具变量假设下对因果假设的检验；效应估计对应的是遗传差异所代理的长期暴露差异。临床剂量、短期干预效果需另有证据，不从 MR 点估计直接换算。

完成判据：清单 20 个主项都有对应段落或「不适用」及原因；数据与代码的获取位置已写明。

## 路径 B（多变量）

1. 每个暴露仍按 A1 的阈值选位点，再取并集；一个位点可以与多个暴露相关。
2. `MVMR::strength_mvmr` 报告每个暴露的条件 F。条件 F≤10 的暴露不解释为其直接效应已得到支持。
3. 主估计用 `ivw_mvmr` 或 `mr_mvivw`，记录函数名。`pleiotropy_mvmr` 的 Q 与路径 A 的 Egger 截距一样写入记录。
4. 图至少包含各暴露直接效应的森林图，出图规则同 A6。

## 路径 C（药物靶点 / 同一基因区）

1. 事先写明基因和窗口（例如转录本起止外扩的 kb 数），窗口来自基因注释版本，写入记录。
2. 工具变量取该窗口内与暴露关联的位点。相关位点不要按路径 A 的全基因组 clump 当成独立工具变量后做随机效应 IVW。
3. 用 `coloc` 对该窗口做暴露与结局的共定位。报告后验概率（H0–H4）。H4 不高时，MR 点估计不解释为「同一因果变异」。
4. 共定位支持后再报告该位点的 Wald 或相关工具变量模型，并写明 LD 参考。

## 路径 D（xQTL）

按 SMR 官方说明准备 GWAS 与 xQTL 输入（效应等位基因、频率、LD 参考）。运行 SMR 与 HEIDI，记录 `--heidi-mtd`。HEIDI 提示异质时，该基因不解释为表达中介已成立。

## 路径 E（单样本）

个体水平数据用两阶段最小二乘，记录协变量（至少包括主成分、年龄、性别，若这些变量在该设计中是混杂）。平均 F≤10 时，估计会朝向普通回归的混杂方向，结论中写明，不与路径 A 的「偏倚朝向无效」混用。

## 停下条件

出现下列任一条时停止交付因果结论，只交付运行记录和原因：

- 暴露或结局汇总统计没有可追溯的编号和下载日期
- 协调后 SNP 数为 0
- 祖先与 LD 参考人群不一致且记录中没有写明理由
- 主分析列使用了会做欠离散校正的 `mr_ivw`，同时又把它当成唯一主分析
- 结果表数字无法在本次输出中复核
- 把 `01_样例_sample/` 的 TOY 图或表写成真实暴露–结局结论
