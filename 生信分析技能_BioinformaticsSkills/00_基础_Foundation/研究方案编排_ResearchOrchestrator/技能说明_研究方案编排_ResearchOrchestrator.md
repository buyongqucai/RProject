# 研究方案编排 / ResearchOrchestrator

本技能是生信技能库的**编排入口**。用户只说研究目的时，Agent **必须先按本技能输出完整计划**，再按计划去读并执行对应 `技能说明_*.md`。

配套索引：[`工作流_workflows.json`](../../工作流_workflows.json)、[`技能目录_skill-catalog.json`](../../技能目录_skill-catalog.json)。

## 1. 数据来源

编排本身不产生测序数据；输入为用户的：

- 科学问题 / 假说 / 表型
- 物种、样本类型、是否已有数据
- 可用平台偏好（可选：仅公共库 / 仅自测 / 混合）

## 2. 数据规范（判断是否可开题分析）

开题前至少明确：

| 项 | 最低要求 |
|----|----------|
| 对比设计 | 至少一组对照 vs 处理/疾病；或预后结局定义清楚 |
| 重复 | bulk 建议每组 ≥3；单细胞每组 ≥2 生物学样本更稳 |
| 物种 | 人/鼠等与注释库一致 |
| 公共数据 | 必须后续走 `数据真实性验证_DataAuthenticity` |

信息不足时：先向用户列出缺失项，再给「暂定计划」。

## 3. 何时选用本技能

- 用户描述研究目的、要「做个分析方案/计划」
- 不确定该用转录组还是单细胞、要不要代谢/生存验证
- 需要从本库**组合多个技能**成一条可执行路线

不适用：用户已明确「只跑某个已指定 GSE 的固定脚本」且无需方案层（可直接进对应技能）。

## 4. 数据处理方法（编排流程）

```text
研究目的
  -> 归类意图（机制/预后/代谢/菌群/调控/多组学…）
  -> 匹配 工作流_workflows.json 模板（有则套用，无则现场组合）
  -> 查 技能目录_skill-catalog.json（research_intents / data_types）
  -> 强制依赖：公共数据→真实性；出图→可视化规范；样例/交付物→统一交付规范
  -> 输出下方「固定计划模板」7 章
  -> 再依次打开列出的 技能说明_*.md 执行
```

## 5. R 包与软件栈（强制）

编排层本身以文档与 JSON 为主；执行阶段使用各子技能的 R 包表。汇总时必须从子技能抄录，禁止凭记忆杜撰包名。

| 步骤 | 工具 | 作用 |
|------|------|------|
| 读目录 | 读 `技能目录_skill-catalog.json` | 选技能与包列表 |
| 套模板 | 读 `工作流_workflows.json` | 常见研究路线 |
| 执行 | 各 `技能说明_*.md` §5 + `脚本_scripts/` | 真实分析 |

## 6. 数据可视化

计划中的图交付一律遵循 `统一可视化规范_VizStandards`：**DPI≥600；SVG+PNG；图面 English；防遮挡；PlotQA**。  
选图时对照 [高分期刊出图范式](../统一可视化规范_VizStandards/文档_docs/高分期刊出图范式_JournalFigureParadigm.md)（Fig1 轨迹/模块、Fig2 热图·火山·GSEA·KM、Fig3 UMAP·签名·生存），在计划第 6 章写明「图种 → recipe」。  
查 [已跑通范式登记](../统一可视化规范_VizStandards/文档_docs/已跑通范式登记_FrozenParadigms.md)：**`网络药理学_NetworkPharmacology` = frozen**，编排时不得要求「按期刊范式重绘网药网络/韦恩」。  
文件命名、审计表、HTML 样例报告一律遵循 `统一交付规范_DeliveryStandards`（禁止无语义 `plot.png` / `样例报告.html`）。

## 7. 数据结果解读

计划书中的「预期结果」只写可检验的表述；最终结论必须等数据跑完，禁止在编排阶段编造 DEG/通路结果。

## 8. 能否结合其它生信

本技能**调度全部**方法技能顶层：`01_组学_Omics/*`、`02_遗传与变异_Genetics/*`、`03_药物计算_DrugDiscovery/*`、`04_临床预测与统计_ClinicalStats/*`、`05_系统方法_SystemsMethods/*`、`06_已落地流水线_ProductionPipelines/*`（布局见 [目录重构说明_LayoutMigration.md](../../目录重构说明_LayoutMigration.md)），并强制组合：

- [`统一可视化规范_VizStandards`](../统一可视化规范_VizStandards/技能说明_统一可视化规范_VizStandards.md)
