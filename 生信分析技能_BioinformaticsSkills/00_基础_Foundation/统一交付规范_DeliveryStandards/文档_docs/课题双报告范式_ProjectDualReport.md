## 2. 论文式报告（版一）— 章节骨架

对齐婷婷「博士论文行文」扩写结构（结论先行、少重复）：

1. **页首警示**（计算预测 / TOY / BLOCKED；禁止疗效措辞）  
2. **摘要（结论先行）** — 3–6 句：做了什么、关键数字、主假说轴、没证明什么  
3. **研究问题** — 锁定可写表述（参考课题 ResearchPlan）  
4. **数据与设计** — 队列/组方/疾病/库清单（短）  
5. **结果一…N** — 按科学流程分节（网药例：疾病靶点 → 药物靶点 → 交集与网络 → 富集 → PPI）。  
6. **讨论** — 与文献对照点；反面口径（共享模块富集 ≠ 病因）  
7. **局限**  
8. **方法摘要** — 文末短段（细节留给方法论报告，避免两份长文互抄）

### 2.1 嵌图与分析（强制 · 对齐婷婷金标）

| 要求 | 合格 | 不合格 |
|------|------|--------|
| 图册覆盖 | 课题轨 B / 标准图序**交付 PNG 全量**进入论文式正文（按流程编排） | 只链到 `图注与解读说明.html`、或只嵌 3–5 张「代表图」 |
| 每图结构 | `<figure>` 图 + 中英图注 + **紧随 ≥1 段结果分析**（数字/含义/不证明什么） | 只有图无字、或图注一句带过 |
| 去重 | 同一 PNG 在**本份报告内**只出现一次 | 正文与附录重复同一张 |
| 路径 | 相对路径；图文件落在报告旁 `图片文件/`（或可打开的相对链）；生成后校验坏链=0 | 绝对盘符、或链到打不开的路径 |
| 图面 | English（VizStandards）；正文中文 | 图面堆中文标签冒充规范 |

版式：侧栏导航或顶栏 TOC；期刊 muted 色可参考 VizStandards。

## 3. 方法论报告（版二）— 章节骨架

对齐婷婷/琪乐无穷「方法论报告」+「概念原理」职责任务（讲清 *怎么做* 与 *怎么读*）：

1. **声明** — 同页首警示  
2. **分析路线** — 瀑布 / 双口径 / 停层规则（可配方法示意图）  
3. **数据库与阈值** — 表格式；含日期、过滤、known vs predicted  
4. **软件与脚本** — 可复现入口（相对路径）  
5. **质控与异常** — 脚注级事实（如剔除非基因、混条审计）  
6. **图册阅读指南（嵌图）** — 对交付图册**全量**按「怎么读」重述：每图仍是 图+图注+分析，但角度是阈值/口径/误读点（与论文式结果叙事互补，允许同图源在两份报告各出现一次）  
7. **与论文式报告的分工** — 明确「数字以 `_stats.json` / 结果表为准」

概念版可加「学习目标 / 概念框」；**不得编造未跑步骤**。

## 4. 硬规则

| 规则 | 要求 |
|------|------|
| 数字 | 全部可自结果 CSV / `_stats.json` 复核；禁止手写无出处 KPI |
| 图 | 交付图册全量嵌正文并逐图分析（§2.1）；相对路径；一图一份报告内不重复；坏链 = 不合格 |
| 声称 | 计算预测；不写治疗/确诊/湿实验已验证（除非真有） |
| 双口径 | 疾病等双数字必须同时出现并标注用途（出图 vs 下游） |
| 样例 vs 课题 | 样例用 SampleReportParadigm；课题终局用本文件 |
