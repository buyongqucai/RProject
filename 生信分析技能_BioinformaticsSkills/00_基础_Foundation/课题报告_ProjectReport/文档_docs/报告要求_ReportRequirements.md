# 课题报告要求（SSOT）

> 没有另行说明时，课题终局报告按本文件写。样例 HTML 仍用 [`样例报告范式_SampleReportParadigm.md`](../../统一交付规范_DeliveryStandards/文档_docs/样例报告范式_SampleReportParadigm.md)，不得拿样例骨架冒充终局报告。  
> 页面函数：[`../脚本_scripts/report_page.py`](../脚本_scripts/report_page.py) 的 `page()`。写出后调用 `check_html`。  
> 轨 B `交付文件/图注与解读说明.html` 是图册解说，不替代本双报告。

## 1. 三件套

| 文件 | 读者 | 写什么 |
|------|------|--------|
| `00_报告入口_index.html` | 所有人 | 链到下面两份、图注包、声明 |
| `01_论文式报告_PaperStyle.html` | 审稿 / 写论文 | 结论先行，结果分节，逐图一次，讨论与边界 |
| `02_方法论报告_Methodology.html` | 复现 / 答辩方法 | 库、阈值、脚本、口径、怎么读图 |

存放：课题 `01_分析报告_AnalysisReport/03_最终报告_FinalReport/`。对外以 HTML 为准。数字以结果 CSV / `_stats.json` 为准，两份报告不各写一套对不上的 KPI。

## 2. 版式

调用 `page(title, side_title, side_sub, nav, body)`。

- 左侧粘性目录，正文在右，`IntersectionObserver` 标出当前节。
- `nav` 的锚点与正文 `h2` 的 `id` 一一对应。
- 窄栏居中、只有顶栏链接、把全部图堆在一个「图」标题下，都不算完成。
- 图用 `<img src="图片文件/…">` 相对路径。图文件放在报告旁的 `图片文件/`。单文件外发时可以改用 base64，同一张图在一份 HTML 里只嵌一次。
- 正文不写盘符路径。

## 3. 文字

### 3.1 论文式章节

每节都有正文，不能只剩标题。

1. 页首警示：计算预测；写明 provenance（REAL / TOY / BLOCKED）。
2. **摘要**（`#abs`）：3–6 句，结论放在第一句。写做了什么、关键数字、没证明什么。
3. **研究问题**（`#question`）：可检验的那一句，不展开成综述。
4. **数据与设计**（`#design`）：队列 / 组方 / 疾病 / 库，短。双口径两个数字都写，并标明哪个用于出图、哪个用于下游。
5. **结果**：按科学流程分节。网药默认：疾病靶点 → 药物与交集 → 网络 → 富集 → PPI → 本课题已做的代谢 / 对接。图放进它所属的那一节，不另开总图库。
6. **讨论**（`#discussion`）：和数字对得上的解释。共享模块富集不等于病因。
7. **局限**（`#limits`）：没跑的步骤写没跑，不写成已经排除。
8. **方法摘要**（`#methods-brief`）：文末短段。阈值细节留给方法论报告。

### 3.2 方法论章节

1. **声明**（`#declare`）：与页首警示同一口径。
2. **分析路线**（`#route`）：瀑布、停层、双口径。
3. **数据库与阈值**（`#thresholds`）：表。含过滤和 known / predicted 的区别。
4. **软件与脚本**（`#scripts`）：可复现入口，相对路径或技能内脚本名。
5. **质控**（`#qc`）：已经发生的异常和处置。
6. **图册阅读指南**（`#guide`）：嵌入与论文式相同的去重图集。角度是怎么读、阈值、误读点。
7. **分工**（`#division`）：论文式写结果和边界；本份写口径。数字以哪份表为准写清楚。

### 3.3 每张图（分块详写 · 强制）

对齐高分刊分区（详见 [`图后分块依据_FigBlockRationale.md`](图后分块依据_FigBlockRationale.md)）：

- **论文式 ≈ Results 顺序单元**（问题 → 发现 → 直接解读 → 边界）。
- **方法论 ≈ Methods + 图注**（怎么读图 → 可复现流程 → 参数阈值 → QC/误读）。

图后**禁止**单段空评、禁止「见某某节/同图块」式甩锅。必须用 `figure_blocks()`；两份报告同图不同写法，不得整段互粘。

#### 3.3.0 充实度硬规则（论文式 + 方法论共用）

下列为**强制**，`check_html` 可抽检违规措辞：

1. **自洽可读**：每一块必须写全，读者**不必翻**到另一份报告或另一块才能懂本块。禁止「见方法论」「见 protocol/params」「详见 STATUS/脚本」「不在此处展开」等推诿句（可写脚本**文件名**与函数名作为事实，但参数与步骤仍须写在本块）。
2. **禁止过度精简**：每一块至少 **2 段**（或 1 段 + ≥3 条列表）；总可见汉字（去标签）建议 ≥120 字/块。Nature 风格 Results：**写清楚观测与直接解读**，不是电报体。
3. **禁止多图共用同一句空话**；KEGG/富集须落到本图 term / 通路号 / 数字。
4. 图面 English；块内正文中文；块与块视觉分开。

#### 论文式 — 每图必写四块

| 顺序 | class | 标题（可微调） | 写什么（checklist） |
|------|-------|----------------|---------------------|
| ① | `setup` | 问题与设计要点 | **写全**：本图科学问题；队列/样本来源；对比组与终点；本分析在证据链中的位置。可用 2–4 句。**禁止**「设计见课题终点、步骤见方法论」；协议细节（包名、参数）仍留给方法论，但**设计本身必须在本块说清**。 |
| ② | `findings` | 主要发现 | **展开写观测**：轴/几何上看到什么；哪些显著/不显著；方向与量级；关键数字。并写清本发现所处的**生理/病理功能层面**（例如炎症–免疫转录重编程、抗原呈递等），以及与**后续分析**的直接关联（为 GO/KEGG/一致集/ROC 提供什么输入）。不是只报坐标含义。 |
| ③ | `takeaway` | 直接解读 | **至少两段**：本图支持什么解释；如何衔接上一结果与下一结果。可点到生物学意义，复杂文献大战留给 `#discussion`。**禁止**单句打发。 |
| ④ | `boundary` | 边界（不能证明什么） | 用列表写清 2–4 条本图**不能**支持的声称，并各加半句「为何不能」（设计/终点/统计效力）。禁止只写一句总括。 |

可选：`chain`。论文式**不强制**逐步协议，但 setup **不得省略设计叙述**。

#### 方法论 — 每图必写四块

| 顺序 | class | 标题（可微调） | 写什么（checklist） |
|------|-------|----------------|---------------------|
| ① | `legend` | 图面与统计标注 | **充分说明**：轴、分面、颜色、点大小、阈值线、误差条、n、展示统计量；如何从左到右/从上到下读；哪些数值必须与哪张结果表字段一致。禁止两行电报。 |
| ② | `protocol` | 可复现流程 | **逐步写清**：数据来源（accession/路径）；纳入排除；**使用的语言、R/Python 包与关键函数名**（如 `limma::eBayes`、`clusterProfiler::enrichGO`、`prcomp`、`save_plot_pub`）；脚本相对路径；输出表/图文件名。禁止「读入→质控→出图」三级空话。 |
| ③ | `params` | 参数与阈值 | **写明函数↔参数**：例如 `pAdjustMethod="BH"`、`\|logFC\|>1`、`adj.P<0.05`、`top_n=10`、PCA 基因筛选规则等。数据按什么规则过滤必须落在本块。**禁止**「参数见脚本/STATUS」一句话；禁止引用另一块代替本块。 |
| ④ | `pitfall` | 质控与误读点 | **扩充**：已发生 QC 与处置；≥2 条误读 + 正确口径；与相邻图种的易混点（如箱线 vs ROC、韦恩中心 vs 一致集规则）。禁止三条超短 bullet 无解释。 |

#### 写法与排版

- 每块独立色块；可用短段落 + 列表。
- 对接拼图在图片目录则必须进图集；未手调的在局限写明编号范围。

## 4. 细节与完成判据

- 以内容哈希去重。同字节只嵌一次。两份报告各自嵌这同一套。
- 缺图、未登记的多余图、坏链、一份报告内重复路径或重复 MD5：生成失败。
- `check_html(html, "paper"|"method"|"index")` 通过。领域技能若禁止某个词（网络药理学禁止正文出现「治疗」二字，含否定句），把该词传给 `forbidden`。
- STATUS 写 `dual_report`、嵌图数、`data_provenance`。
- 不编造未跑步骤，不把 TOY / BLOCKED 写成真实结论。

## 5. 不在本技能里决定的事

出图 recipe、韦恩引擎、对接流程分别跟着领域技能。本技能只规定报告怎么排、怎么写、怎么嵌。
