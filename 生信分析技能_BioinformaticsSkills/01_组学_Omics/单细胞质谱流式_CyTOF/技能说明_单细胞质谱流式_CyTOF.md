# 单细胞质谱流式 / CyTOF

## 1. 数据来源

CyTOF FCS

## 2. 数据规范（判断是否可用）

输入完整可溯源；分组/标注来自官方或实验记录；禁止编造结果数字。

## 3. 何时选用本技能

- 蛋白水平单细胞分群
- 山水用途层标签：病因-细胞

不适用：输入类型不匹配或仅需其它技能可覆盖的步骤。

## 4. 数据处理方法

预处理→降维→分群→差异
