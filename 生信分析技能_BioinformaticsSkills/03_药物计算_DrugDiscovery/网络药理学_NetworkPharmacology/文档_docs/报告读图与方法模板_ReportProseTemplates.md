# 报告读图与方法模板（占位符）

> **SSOT：** 论文版细读段 / 方法版模块骨架的可复用句式。  
> **写法约束：** 双报告技能（结果口气；禁说明书套话）。图种口径对齐出图约束 **§I**。  
> **用法：** 替换 `{{占位符}}`；数字只从本课题表/STATUS 抄。

占位符一律双花括号。未填不得进交付正文。

---

## 0. 通用分点骨架（论文版 · 每图一段 · **强制分点，勿混写**）

HTML 交付用 `<ol class="ana-points">`；正文口吻仍是结果口气，禁止说明书套话。

```html
<strong>分析：</strong>
<ol class="ana-points">
  <li><strong>图种与口径：</strong> {{图种中文名}}（{{英文短名}}）；{{口径/输入一句}}。</li>
  <li><strong>怎么看：</strong> {{轴/颜色/椭圆或节点/格子含义}}。</li>
  <li><strong>画面关键数字/名字：</strong> {{图上写出的名字与数值，逐条点名}}。</li>
  <li><strong>回答什么：</strong> {{对齐 §I「回答什么」的一句}}。</li>
  <li><strong>解读边界：</strong> {{勿写成 · 对齐 §I}}。</li>
</ol>
```

官方通路图等可再加一项 `<li><strong>观察与语境：</strong> …</li>`（插在「画面关键数字」与「回答什么」之间）。

## 1. 图种 01 · 疾病多库韦恩

### 1.1 论文版细读（分点）

```html
<strong>分析：</strong>
<ol class="ana-points">
  <li><strong>图种与口径：</strong> 疾病多库韦恩（Disease databases Venn）；<strong>韦恩全量</strong>（GeneCards 全量，不作 Relevance 过滤）。</li>
  <li><strong>怎么看：</strong> 每瓣=一库；重叠区数字=共有基因；下方 Size of each list / specific-or-shared 条为规模与共享层级。</li>
  <li><strong>画面关键数字/名字：</strong> {{库名1}} {{n1}}、{{库名2}} {{n2}}、{{库名3}} {{n3}}…；{{交集/特异要点}}。</li>
  <li><strong>回答什么：</strong> 各库对 {{英文病名}} 相关基因的覆盖与重叠有多大（广度，非下游药病交集）。</li>
  <li><strong>解读边界：</strong> 不得把全量韦恩交集写成下游药病交集；双口径见药病韦恩（图种 02）。</li>
</ol>
```

### 1.2 方法版模块骨架（八项可填）

```text
### 疾病多库韦恩（图种 01）

1. 为何采用：用多库并集/重叠图回答「各库覆盖与共识有多大」；不用单库名单代替多库结构。
2. 数据来源：{{库列表与访问/版本}}；原始路径 `{{原始相对路径}}`；韦恩全量表 `{{VennFull相对路径}}`。
3. 筛选标准：韦恩用 GeneCards **全量**；CTD 用 {{curated|any}}；其它库 {{纳入规则}}；剔除 {{剔除词}}。下游并集另用 GeneCards Relevance≥{{阈值}}（本图不采用该过滤）。
4. 数据处理与函数：基因 symbol 标准化后按库建集合；出图调用 `脚本_scripts/weishengxin_venn_lib.py` 的 `write_disease_venn` / `render_jvenn_sets`（本地 jvenn，微生信风格）。
5. 参数与取值原因：集合顺序 {{顺序}}；配色沿微生信默认/课题锁定；画幅左留白 ≥56px，避免集合名裁切。
6. 输入与输出：输入各库 gene 列；输出 `{{图片相对路径}}`（SVG+PNG）。失败停在缺库文件时标 `BLOCKED_EXTERNAL`，不编造基因。
7. 结果怎么读：见出图约束 §I 图种 01；以画面数字与 `{{汇总表路径}}` 为准。
8. 解读边界：只描述库间覆盖/重叠；不声称疾病机制已证实，不与药病交集数字混用而不声明双口径。
```
