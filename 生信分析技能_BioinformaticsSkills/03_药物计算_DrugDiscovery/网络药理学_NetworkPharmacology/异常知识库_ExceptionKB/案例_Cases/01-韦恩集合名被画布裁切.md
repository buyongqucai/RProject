# 五库韦恩集合名被画布裁切

- 日期/体系：2026-11-03；Hp 慢性非萎缩性胃炎五库韦恩
- 状态：已解决

## 症状（怎么发现的）

图上 GeneCards 只剩 eneCards。后来又把默认引擎改成 R 的 VennDiagram，画面不再是复刻的 jvenn。

## 判定（真异常还是假象）

微生信页面导出 SVG 固定 500×695，集合名画在画布边缘，裁白边补不回已经出界的字。VennDiagram 能把名字画全，但不是项目里的 HTML 复刻。

## 补救（按序尝试）

1. 用 `render_replica_svg()`，页面是 `脚本_scripts/_jvenn_assets/jvenn_runner.html`。
2. 导出后扩大 SVG 视口，光栅化按 SVG 自己的宽高。
3. 目视集合名是否完整。空库仍画圈，计数为 0。
4. 不要改用 `np_plot_disease_db_venn` / `np_save_venn`。

## 何时放弃

用户该次明确说「用网站」时，才调用 `render_jvenn_svg()`，并仍须保证集合名完整。

## 复盘（根因一句话 + 预防）

默认路径必须是本地 HTML 复刻，见出图约束 §G。
