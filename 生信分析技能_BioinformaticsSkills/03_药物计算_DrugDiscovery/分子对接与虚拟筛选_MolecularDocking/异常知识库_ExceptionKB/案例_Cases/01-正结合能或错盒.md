# 结合能为正 / 姿态贴盒缘 — 错盒

- 日期/体系：多批次（AutoDock-GPU 路线）
- 状态：已解决（路线固化）

## 症状（怎么发现的）
`summary_adgpu.csv` 出现 affinity > 0 kcal/mol；或 PyMOL 里 pose 贴在盒子边缘/与蛋白无相互作用。

## 判定（真异常还是假象）
真异常（对接问题而非分析假象）：正结合能 + 盒缘姿态 ⇒ 盒子没罩住真实口袋（盲盒/固定 22Å 盒的典型后果）。
辅助核对：`center_source` 登记的定心方法（共晶包盒 / AutoSite / 回退）是否与该任务匹配。

## 补救（按序尝试）
1. `技术路线_AutoSite_AutoDockGPU.md` §2–§3 重定盒：AutoSite 找口袋 → 重新包盒 → 重跑对接。
2. 有共晶配体：共晶配体质心包盒（决策树首选）。
3. 重跑后仍正结合能：查受体清洗（质子化/电荷/缺链）与配体 3D（案例 02），换来源再试一轮。

## 何时放弃
两轮重定盒（AutoSite + 共晶/回退）仍正结合能 ⇒ 该蛋白-配体组合报告「无可信结合姿态」，不交付假数字。

## 复盘
根因：沿用固定盒/盲盒。预防：任务级强制 `center_source` 登记；交付门禁查正结合能。
