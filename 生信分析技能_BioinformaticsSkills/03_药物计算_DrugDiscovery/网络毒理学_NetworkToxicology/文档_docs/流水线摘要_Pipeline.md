# 网络毒理学流水线摘要

库档位与 URL：[`数据库可抓取登记_FetchRegistry.md`](数据库可抓取登记_FetchRegistry.md)。

1. **定暴露物**：化学名 / CAS / 代谢物；PubChem 解析 CID + SMILES。失败则停，不编造结构。  
2. **策展网络**：读入用户已下载的 CTD 化学–基因、化学–疾病（及需要时化学–表型）表；商业使用先确认 CTD 许可。  
3. **可选预测层**：STP 或 SEA；结果表字段 `evidence=predicted`，不与 CTD 行合并成一种证据。  
4. **可选菌群轴**：gutMGene 手工导出代谢物–基因–微生物；再按步骤 1–3。  
5. **疾病或毒性基因**：Open Targets，或与网药相同的疾病库手工导出。取交集。  
6. **机制**：交集基因做 PPI（STRING）与通路富集；AOP 用官网 XML 或社区 API（失败则跳过并写明）。  
7. **可选对接**：核心暴露物 × 核心靶点，走分子对接技能。  
8. **交付**：中英文件名、图面 English、`DATA_SOURCE.md`、审计表；缺库步骤标 `BLOCKED_EXTERNAL`。

完成判据：交集表可追溯到下载文件或 API 响应；预测边与策展边可分开筛选。
