# ADA_Adenosine_1ADD

场景 A2。失败的人源 7RTG 对接初态不续跑。

- 受体：鼠源 ADA，PDB 1ADD 链 A，2.40 Å
- 金属：该晶体的 Zn，坐标不改
- 配体：腺苷。1-脱氮腺苷的 C1 改为 N1，其余重原子坐标不变
- 侧链：保持 1ADD 结合态，不放大口袋
- 水：全部去掉。离 Zn 最近的晶体水会指向 C6，换成腺苷 6-氨基后重叠

结论写成「鼠源 1-脱氮腺苷实验位姿导出的腺苷」，不是腺苷共晶。
