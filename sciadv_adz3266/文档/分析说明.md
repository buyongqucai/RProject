| 轨道 | Bulk DEG | MAMs 基因集 | 细胞定位 |
|------|----------|-------------|----------|
| 人源 | GSE79962（SCM vs Control，203 显著 DEG） | MAMs_基因集_人.csv（48 基因） | 无（项目内无人 scRNA） |

## 交集结果（padj<0.05 且 |log2FC|>1）

### 人源
- **严格标准交集：0 基因**
- 说明：48 个 MAMs 基因中，44 个出现在 GSE79962 全部 DEG 中，但无基因同时满足 |log2FC|>1 与 padj<0.05
- **宽松标准（padj<0.05，不限 log2FC）：15 基因** → 见 `结果/表格/人源_MAMs交集_宽松_padj0.05.csv`

### 鼠源
- **严格标准交集：2 基因**
  - **Bnip3**（上调，log2FC=2.28）：Table S1 主要定位于 **Cardiomyocyte**（avg_log2FC=0.71）
  - **Rras2**（下调）：未出现在 Table S1 marker 列表中

## 如何运行 R 脚本

```r
setwd("sciadv_adz3266/代码")
source("运行全部分析.R", encoding = "UTF-8")
```

需本机安装 R 且已运行 GSE79962 / GSE171546 预处理以导出表达矩阵。

## Python ML 联动

机器学习模块位于 `E:\PythonProject\差异分析与单细胞测序`。
先运行 R 导出 `结果/导出/*_expr_matrix.csv` 后，再执行：

```bash
cd E:\PythonProject\差异分析与单细胞测序
python run_all.py
```

R 原生 ML 不支持 CUDA；GPU 训练请使用 Python 侧 XGBoost-GPU / PyTorch。
