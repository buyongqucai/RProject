# 09: 按规模选择 CPU 或 GPU，并核对整条调控输出

**类别:** enhancement
**标签:** 已完成
**Blocked by:** 08-小矩阵核与异步写盘.md

**What to build:** 上次对照只做了很小矩阵上的建网。补一条规模阶梯，标出 1.4 和 1.4.3 里 CPU 更快的段落。显式 `cpu` / `gpu` 保持原样。`auto` 按这次测量选择更快的一侧。小矩阵上若完整 SVD 比迭代截断更接近已安装的 R，CPU 建网改走那条。再用同一套细胞下标跑通张量到 dRegulation，核对 distance 和 p.adj。

- [x] 阶梯上每条路径对没有 GPU 的 R，最大绝对差小于 1e-5，置零位置相同
- [x] 写出哪一段 CPU 更快，`auto` 按该结果选择，显式 `gpu` 仍走 GPU
- [x] 三张网的后半段对 R 1.4 的 distance、p.adj 有记录

## Notes

2026-10-02。1 个 BLAS 线程。阶梯 24×18、40×30、80×60、160×100、320×150。1.4 的 GPU 在这五档都慢于 CPU，320×150 上 GPU 10.000 秒、CPU 截断 0.858 秒。1.4.3 的 GPU 五档都更快，320×150 上 0.021 秒，CPU 0.061 秒。

短边不超过 128 的 1.4 CPU 改走完整 gesdd。24×18 对 R 从 1.298e-13 收到 2.931e-14。160×100 收到 1.416e-14。320×150 仍用迭代截断，对 R 5.546e-14。置零差都是 0。

28 基因、3 张网，张量到 dRegulation。1.4.3 的 R、以及 1.4 和 1.4.3 的 CPU/GPU，对 R 1.4 的 distance 和 p.adj 最大绝对差都是 0。`auto`：1.4 用 CPU，1.4.3 在有 CUDA 时用 GPU。显式 `gpu` 不改。
