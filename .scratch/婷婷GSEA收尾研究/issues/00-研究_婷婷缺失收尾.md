## 3. 一手来源与证据

### 3.1 GSEA 方法

- GSEA User Guide：`https://docs.gsea-msigdb.org/GSEA/GSEA_User_Guide/`
  - GSEA 检验预先定义的基因集是否在排序基因列表一端富集。
  - 官方指南要求使用完整排序数据，不建议先按低方差/低表达随意过滤；低贡献基因通常位于列表中部。
  - 多基因集分析必须做多重检验校正。
- fgsea 官方包：`https://bioconductor.org/packages/release/bioc/html/fgsea.html`
  - 本地教程：`E:\R-4.6.0\library\fgsea\doc\fgsea-tutorial.Rmd`
  - `fgseaMultilevel()` 支持 `scoreType = c("std","pos","neg")`，结果含 `ES/NES/pval/padj/size/leadingEdge`。
  - 当基因级统计量的正负不平衡时，源码会警告并可能把部分 P 值、NES 设为 NA。对非负 `distance`/`KL`，应显式使用 `scoreType="pos"`，不要假装成上下调双侧 GSEA。
- clusterProfiler 官方包：`https://bioconductor.org/packages/release/bioc/html/clusterProfiler.html`
  - 本地版本 4.20.0；`gseGO()`、`gseKEGG()` 默认 `minGSSize=10`、`maxGSSize=500`、`pAdjustMethod="BH"`、`method="multilevel"`。
  - `gseGO/gseKEGG` 经 `enrichit::gsea_gson()` 继续传递 `scoreType`、`eps`、`seed` 等参数。

### 3.2 scTenifoldKnk 排名量含义

- 官方仓库：`https://github.com/cailab-tamu/scTenifoldKnk`
- 方法论文：Osorio et al., *Patterns* 2022，DOI `10.1016/j.patter.2022.100434`。
- 本地包源码：`E:\R-4.6.0\library\scTenifoldKnk\DESCRIPTION`，并用 `scTenifoldKnk::dRegulation()` 核对。
- `dRegulation()` 的一手定义：
  - `distance` = WT 与 KO 流形坐标之间的欧氏距离；
  - `Z = scale(nD)`，其中 `nD` 是 Box-Cox 变换后的距离；
  - `FC = distance^2 / mean(distance^2)`；
  - P 值来自理论卡方零分布并做 FDR。
- 因此 `distance`/`Z` 表示**扰动幅度相对高低**，不表示基因表达上调或下调。`Z<0` 仅表示低于全基因平均水平，不是“下调”。

## 4. 推荐方法

### 4.1 主分析：scTenifoldKnk Knk × AHR

对 TREM2、M2-like 分别做独立 pre-ranked GSEA，不合表、不合并排名。

#### 输入规则

1. 读取每个亚群 AHR 的完整 `扰动_Dr.csv`。
2. 剔除 `gene == "AHR"`；对照基因不在这张 AHR Dr 中，不需额外删除。
3. 基因名保留全部可分析基因，不先按 FDR 过滤。
4. `distance` 降序，作为非负“扰动强度”排名。
5. 用 `org.Hs.eg.db 3.23.1` 做 SYMBOL→ENTREZID；一对多/多对一时确定性保留排名最高者，保存映射审计表。
6. 去除重复 Entrez ID；不删除未映射基因的结果来源，只在审计表中记录映射率。

#### 统计规则

- 方法：`clusterProfiler::gseGO()` + `gseKEGG()`，底层 multilevel GSEA。
- GO：BP、CC、MF 分开；KEGG：`organism="hsa"`。
- `minGSSize=10`，`maxGSSize=500`；敏感性分析可重复 `minGSSize=15`，但不得挑最好看的版本作为主结果。
- `pvalueCutoff=1` 保存完整结果；随后按计划过滤 `p.adjust<0.05` 且 `qvalue<0.2`。
- `pAdjustMethod="BH"`，固定随机种子，`eps=0`，`nPermSimple=1000`。
- 对非负 `distance` 显式使用 `scoreType="pos"`；如果当前 clusterProfiler 透传不稳定，则用 `fgsea::fgseaMultilevel(pathways, stats, scoreType="pos")` 作为统计主实现，再用 clusterProfiler 只做 GO/KEGG 注释和出图。
- 不使用 `Z` 作为上下调统计量。可把 `Z` 作为敏感性排名，但结果只能解释为相对扰动幅度，不能解释方向。

#### 解释口径

可写：

- “在高虚拟扰动端富集的候选通路。”
- “全排序 GSEA 提示该通路基因整体更集中在 AHR 虚拟扰动较大的基因中。”
- “计算预测，需独立数据或湿实验验证。”

不可写：

- “AHR 敲除激活/抑制该通路。”
- “这些基因表达上调/下调。”
- “GSEA 证明 AHR 是该通路的因果调控因子。”
- “响应基因等于 Seurat DEG。”

### 4.2 次分析：GenKI KL 全排序 GSEA

仅在希望解释 GenKI 排名时做，标为探索性、与 Knk 完全分栏。

- 输入完整 `KL排序_RankKL.csv`，剔除 AHR。
- `KL` 降序，`scoreType="pos"`；不把 `hit_fraction` 与 KL 任意相乘造分数。
- 对结果同时报告 KL、hit、hit_fraction；leading-edge 基因须回查 GenKI 稳定性。
- TREM2 无其他过线响应基因，GSEA 仍可从全排名探索，但不能反写成“有响应基因”。
- GenKI GSEA 与 Knk GSEA 不比较谁更优、不合并 NES，不套用 Knk 的 `p.adj`。

推荐默认：**先完成 Knk 主分析；GenKI GSEA 作为可选补充**，因为计划明确缺的是 `扰动_Dr.csv` GSEA。

### 4.3 琪乐无穷可复用与不可复用

| 可复用 | 需要改 |
|---|---|
| `distance` 降序、剔除敲除基因 | 不预设 3 个突触条目 |
| `gseGO` 全排序入口、`minGSSize=10/maxGSSize=500` | 婷婷跑 BP/CC/MF + KEGG，不只 BP |
| GSEA 曲线、NES/P 热图、PNG+SVG | 图只画通过条目或明确标出无通过 |
| `08_` 输出编号和跨亚群目录 | 新增映射审计、完整表、阈值和版本记录 |
| 空结果也要报告 | 不把 nominal P 或 Top50 当显著通路 |
