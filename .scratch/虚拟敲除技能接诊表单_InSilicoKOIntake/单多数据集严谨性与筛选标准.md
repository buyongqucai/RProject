## 1. 单数据集 vs 多数据集差在哪？严谨性会变吗？

先分清三种「多数据集」——**严谨性完全不同**：

| 做法 | 在做什么 | 严谨性 | 是否推荐用于本课题 |
|------|----------|--------|-------------------|
| **S：单数据集** | 只用一套 GSE，在其亚群上跑 scTenifoldKnk | 设计简单、批次少；**外推弱**（结果可能绑死该实验室条件） | 可作最小可发表探索 |
| **M-平行（多证据链）** | 多套数据**各自**建网、各自敲，再比较 DR 基因/通路**重叠** | **通常更严谨**：独立重复式支持；阴性/阳性可互证；不假装「一个超大实验」 | **推荐**（对应 M3） |
| **M-硬合并** | 不同 GSE/组织/技术拼成**一个** count 矩阵再敲一次 | **风险高**：批次、解离、测序深度、基因空间不同会进网络，扰动可能是伪影 | **默认禁止**（除非同组织同平台且做整合+敏感性分析并写清） |

### 严谨性怎么变（直观）

```text
单数据集：
  优点 = 干净、可复现路径短
  缺点 = 「只在这一套细胞里成立」；审稿常问外推

多证据链（推荐的多数据集）：
  优点 = 图谱里成立 + 损伤 TG 里也成立 → 结论更硬
  缺点 = 工作量大；若两链冲突要诚实报告，不能只报好看的一条
  注意 = 各链问题略有不同（基底 vs 损伤态），重叠才是「稳健」，不重叠不是自动失败

硬合并多数据集：
  优点 = 细胞数虚高、一篇图好看
  缺点 = 严谨性往往下降（除非严格 QC+整合+留一数据集敏感性）
```

**和 scTenifoldKnk 原文一致的点：**  
工具本身**不要求**疾病对照样本；它要求的是「某一群细胞的 WT 表达矩阵」。  
所以「多数据集」在方法学上合法的主形态是：**多个细胞群体 / 多个研究场景，分别虚拟敲除**（作者也用多场景、甚至整合公开内皮细胞再系统敲）。  
「多数据集」**不等于**「一定更科学」——**平行证据链 ↑ 严谨性；乱合并 ↓ 严谨性。**

## 2. 数据集筛选标准（纳入 / 排除 / 打分）

用于决定「能不能进 scTenifoldKnk 主分析」。不满足硬门槛 → 不得标为 `dataset_fit=适用主分析`。

### 2.1 硬门槛（缺一不可 → 排除主 VKO）

| ID | 标准 | 为何 |
|----|------|------|
| H1 | 物种 = **小鼠**（本题已锁定） | 符号与模型一致 |
| H2 | 分子层 = **scRNA 或 snRNA 的细胞/核 × 基因 counts** | bulk 不能建 scGRN |
| H3 | 组织优先 **TG**；非 TG 不得冒充 TG 主结论 | 课题截图 Phase1 |
| H4 | 公开可下载矩阵或作者门户等价物，登录号可溯源 | 真实性 / 复现 |
| H5 | 敲除基因 `Cplx2` 在拟分析群体中**可被检测到**（下载后实测；过稀则该亚群排除） | 工具与 Issue #33：靶基因须留在矩阵 |
| H6 | 拟敲群体细胞数足以建网（经验：宜 ≥ 数百；`< nc_nCells` 默认 500 时须下调参数并披露） | scTenifoldKnk 对 N 敏感 |

### 2.2 优先门槛（越高越好；决定主线/辅线）

| ID | 标准 | 权重 |
|----|------|------|
| P1 | 疾病相关性：慢性 IoN-CCI / CION / 临床 TN 模型 > 眶下神经切断 IOT > CFA 炎症 > 仅健康图谱 | 高 |
| P2 | 有清晰**感觉神经元亚群**或可复现作者注释 | 高 |
| P3 | 生物学重复 / 可追踪样本或鼠 ID | 中 |
| P4 | 与 IF 对齐：可分 **Calca+** 与 **Nefh+**（或等价） | 中（TG） |
| P5 | 技术：10x / 主流平台，基因覆盖够突触相关基因 | 中 |
| P6 | 论文层级与方法透明度（eLife/Neuron 等 + 可复现补充表） | 中 |

### 2.3 明确排除（不得作 VKO 输入）

| ID | 排除类型 | 例子 |
|----|----------|------|
| E1 | bulk / 组织均浆 RNA-seq | GSE316925 作 VKO 输入 |
| E2 | 仅非神经元 TG | GSE240432 |
| E3 | 无 counts、仅图或仅 DEG 表 | — |
| E4 | 人数据作本题主分析（物种已锁小鼠；人仅可对照且须另勾） | GSE197289 人侧主敲 |
| E5 | 跨组织硬合并后单次 VKO 当主结论 | TG+Sp5C 糊一锅 |

### 2.4 辅线允许（写进报告但降权）

- **Sp5C** 模型 sc：中枢补充，标题不得写「TG 虚拟敲除主结果」  
- **bulk IoN-CCI**：只做 `Cplx2` 是否 DE 的正交，不做 scTenifoldKnk  
- **CFA 炎症 sc**：敏感性，病种声明 ≠ TN

## 3. 用标准重评当前候选（元数据层；检出率待下载）

评分：硬门槛 Pass/Fail；优先项 高/中/低/无。

| 数据集 | H1–H4 | H5–H6 | P1 疾病 | P2 亚群 | 角色 |
|--------|-------|-------|---------|---------|------|
| **GSE197289 小鼠** | Pass | 待测 | 低（图谱） | 高 | **图谱主链**（基底 VKO） |
| **GSE131272** | Pass | 待测 | **中高**（IOT 神经损伤，非慢性 CCI） | 中（损伤后亚群重塑） | **损伤主链** |
| GSE213105 | Pass | 待测 | 低 | 中高 | 图谱备份 |
| GSE186421 | Pass | 待测 | 中低（炎症≠TN） | 中 | 敏感性可选 |
| GSE316925 | **Fail H2** | — | 很高（IoN-CCI） | — | 仅 bulk 正交 |
| GSE322600 | Fail H3（若要 TG 主结论） | 待测 | 高（CION） | 窄投射群 | 仅 Sp5C 辅链 |
| GSE240432 | Fail（非神经元） | — | — | — | 排除 |

**结论（筛选标准视角）：**

1. **没有**同时 H1–H4 + P1「慢性 IoN-CCI」全满贯的公开 sc 集。  
2. **通过硬门槛且可作主 VKO 的**至少两条：`GSE197289`（图谱）、`GSE131272`（损伤）。  
3. **多数据集若采用 M-平行**：用这两条做双证据链，严谨性 **高于** 只做其中一条；**高于** 把它们硬合并。  
4. 单数据集若只选一个：选 **GSE131272** 更贴「痛/损伤」叙事；选 **GSE197289** 更贴「亚群+IF 标志」叙事——各有缺口，故双链更稳。
