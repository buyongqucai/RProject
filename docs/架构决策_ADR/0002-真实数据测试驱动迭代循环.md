# 0002 — 真实数据测试驱动的迭代循环

- 日期：2026-08-30
- 状态：已接受（用户明确决策）

## 背景

技能库样例多为契约桩（BLOCKED）或模拟数据，无法验证真实流水线逻辑。用户要求：各技能项目下载真实数据做测试，一边测试、一边修改、一边审查，构建迭代循环。

## 决策

1. **真实数据优先**：各技能样例优先接入真实公开数据（GEO/TCGA/PubChem/PDB 等），缓存于样例 `数据文件/` 并在 `DATA_SOURCE.md` 登记 provenance；禁止编造。
2. **循环节奏**：每个技能按「选定测试接缝（seam）→ 红（失败测试）→ 绿（最小实现）→ code-review 双轴审查 → 提交」循环；重构只发生在审查阶段，不在红绿循环内。
3. **规范层级**：医学/生物学/学术规范 > 领域技能已写明条款 > VizStandards/DeliveryStandards > 通用习惯。涉及医学/生物学结论的图表与统计口径，先查领域规范再动手。
4. **一边改动一边提交**：每个循环结束即 git 提交，只暂存当次相关文件。

## 影响

- 测试接缝（seam）按 TDD 技能规则：动手前与用户书面确认，不在未确认的接缝上写测试。
- 真实数据下载需记录来源、日期、许可；大数据文件不入 git（用 `.gitignore` + 缓存目录约定）。
